A project is the starting point for every piece of research in Peekator. This guide shows you how to create a new project from the homepage, name it, and optionally add context that helps AI features produce more relevant results.

<Steps>
  <Step title="Open the create dialog">
    On the Projects homepage, click **Create new project** in the upper right corner.
  </Step>
  <Step title="Enter a project name">
    Type a clear, descriptive name for the project. This name appears on the project card and helps you find the project later.
  </Step>
  <Step title="Add AI context (optional)">
    Toggle **Context for better AI** if you want Peekator's AI features to use your research and business goals for more tailored results. When enabled, enter:

    - **Research goals**: what you want to learn from this project.
    - **Business goals**: how the findings will be used in your organisation.
  </Step>
  <Step title="Create the project">
    Click **Create project**. The new project card appears immediately on the homepage.
  </Step>
</Steps>

## The project card

Each project card shows:

- **Project name**
- **Start date**: the date the project was created
- **Add survey** and **Add interview** buttons
- **Three-dot menu (⋮)**: access rename, select surveys to delete, and delete project options

## Next steps

After creating a project, add your first survey or interview to start building your questionnaire or discussion guide.

<Note>
  For renaming, deleting surveys, or deleting the project, see [Manage projects](/projects/manage-projects).
</Note>
