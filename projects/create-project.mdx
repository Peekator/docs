A project is the starting point for every piece of research in Peekator. This guide shows you how to create a new project from the homepage, name it, choose the teams that can access it and optionally add context that helps AI features produce more relevant results.

<Steps>
  <Step title="Open the create dialog">
    On the Projects homepage, click **Create new project** in the upper right corner.
  </Step>
  <Step title="Enter a project name">
    Type a clear, descriptive name for the project. This name appears on the project card and helps you find the project later.
  </Step>
  <Step title="Choose teams with access">
    Use **Teams with access** to choose which teams can access the project.

    1. Open the **Teams with access** list.
    2. Select one or more teams.

    [Insert screenshot: Create new project with Teams with access]

    Everyone in a selected team can access the project. Their user role determines what they can do within it.

    For example, a Viewer can access the project in read only mode, while a Collaborator can work on projects that belong to their team.

    <Note>
      You can change project access later from **Edit Project permissions**.
    </Note>
  </Step>
  <Step title="Add AI context (optional)">
    Toggle **Context for better AI** if you want Peekator's AI features to use your research and business goals for more tailored results. When enabled, enter:

    - **Research goals**: what you want to learn from this project.
    - **Business goals**: how the findings will be used in your organisation.
  </Step>
  <Step title="Create the project">
    Click **Create project**. The new project card appears immediately on the homepage.
  </Step>
</Steps>

## The project card

Each project card shows:

- **Project name**
- **Start date**: the date the project was created
- **Add survey** and **Add interview** buttons
- **Three dot menu (⋮):** rename the project, edit project permissions, select surveys to delete or delete the project.

## Next steps

After creating a project, add your first survey or interview to start building your questionnaire or discussion guide.

<Note>
  For renaming, changing project access, deleting surveys or deleting the project, see [Manage projects](/projects/manage-projects).
</Note>
