Peekator provides two AI tools in the reporting section of every survey. Chat with Results lets you ask natural-language questions about your survey data and get AI-generated answers with source citations. Auto-coding groups open-ended text responses into named categories so you can spot themes without reading every answer manually.

## How AI analysis works

Both tools draw on the response data collected in your survey. Auto-coding is applied per question and generates a set of categories that capture the main ideas expressed in free-text responses. Chat with Results uses the full survey data, including auto-coded categories, to answer questions about trends, segments, and key findings.

For best results, run Auto-coding on your open-ended questions before using Chat with Results. When open-ended questions are not yet coded, Chat with Results will show a warning.

<Note>
  For surveys in Interview mode, Chat with Results is called **Chat with Data**. The functionality is identical.
</Note>
