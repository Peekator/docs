Card sort questions ask respondents to organize a set of cards into categories that make sense to them. Use this type for information architecture research, navigation design, and content categorization to understand how your audience naturally groups items.

## Add a card sort question

<Steps>
  <Step title="Click Add Question">
    In the questionnaire builder, click **Add Question** and select **Card Sort**.
  </Step>
  <Step title="Choose the sort mode">
    Select **Closed** (predefined categories) or **Hybrid** (predefined categories plus the ability to create new ones).
  </Step>
  <Step title="Add cards">
    Add each item respondents will sort. Each item becomes a draggable card.
  </Step>
  <Step title="Add categories">
    Add the category buckets respondents will sort the cards into.
  </Step>
</Steps>

## Settings

| Setting | Description |
| --- | --- |
| **Sort mode** | **Closed**: respondents sort cards into your predefined categories only. **Hybrid**: respondents can also create new categories of their own. |
| **Randomize cards** | Shuffle the order of cards each time the question is shown. |
| **Allow continue without completing** | Let respondents proceed even if some cards remain unsorted. |
| **Cards** | Add, edit, remove, or reorder the items to sort. |
| **Categories** | Add, edit, remove, or reorder the category buckets. |

<Tip>
  Use **Closed** mode when validating an existing structure. Use **Hybrid** mode for exploratory research where respondents may see categories you have not anticipated.
</Tip>
