A hidden variable is not shown to respondents. It works in the background and lets you apply the same combination of conditions wherever you need it.

For example, you could create a hidden variable called **UK customer service managers** for respondents who:

- selected _United Kingdom_ as their location; and
- selected _Customer service manager_ as their role.

You can then use that hidden variable in question conditions, group conditions or piping, instead of rebuilding the same rules each time.

## When to use hidden variables

Use a hidden variable when you need to:

- apply the same respondent group to several questions or groups;
- combine answers from more than one question into one reusable segment;
- simplify complex logic in the questionnaire; or
- use a respondent group as a piping source.

You can create a hidden variable for any group of respondents that can be defined by their answers.

## Create a hidden variable

1. Select **Options** in the questionnaire menu.
2. Select **Add hidden variable**.
3. Give the variable a clear, descriptive name.
4. Select **Include** or **Exclude**.
5. Choose whether respondents must meet **All** or **Any** of the conditions.
6. Select the question, operator and answer for each condition.
7. Select **Add another condition** to add more rules.
8. Select **Confirm**.

For example, to create the **UK customer service managers** hidden variable, select **Include** and **All**, then add these conditions:

| Question | Operator | Answer |
| :-- | :-- | :-- |
| Location | **IS** | United Kingdom |
| Job role | **IS** | Customer service manager |

Only respondents who meet both conditions are included in the hidden variable.

## Use a hidden variable in logic

After creating the hidden variable, select it when you add a condition to a question or group.

For example, use **Ask only if** to show a set of customer-service questions only to respondents in the **UK customer service managers** hidden variable.

This is useful when the same segment controls several parts of the questionnaire. If the segment definition changes, update the hidden variable once instead of editing each question or group separately.

## Use a hidden variable for piping

Use a hidden variable for piping when you need to pipe answers multiple times and the standard **Pipe answers** option cannot support the required setup.

1. Create the hidden variable from the relevant earlier answers.
2. Open the later question.
3. Select **Pipe answers**.
4. Select the hidden variable as the source.
5. Complete the target-question setup.

For the target-question rules, see [Piping and Text substitution](/piping-and-text-substitution).

## Test the setup

Preview the questionnaire with different answer combinations before launching.

Check that respondents who meet the conditions are included in the hidden variable, and that questions, groups and piped answers behave as expected.
