Website test questions embed a live website or prototype directly in the survey so respondents can interact with it as part of completing their task. Use this type for usability testing, prototype validation, or evaluating user flows on live sites.

## Add a website test question

<Steps>
  <Step title="Click Add Question">
    In the questionnaire builder, click **Add Question** and select **Website Test**.
  </Step>
  <Step title="Enter the URL">
    Provide the full URL of the website or prototype to embed.
  </Step>
  <Step title="Write the task instruction">
    Enter clear instructions for what respondents should do on the site, for example: `Find the pricing page and note the plan options.`
  </Step>
</Steps>

## Settings

| Setting | Description |
| --- | --- |
| **URL** | The website or prototype URL to embed in the question. |
| **Screen and microphone recording** | Enable recording of the respondent's screen activity and microphone audio during the task. |

<Note>
  The default instruction shown to respondents is: "Browse the site and then click Next."
</Note>

<Tip>
  Make sure the website URL is publicly accessible. Sites behind authentication or paywalls will not load for respondents.
</Tip>
