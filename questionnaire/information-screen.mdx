An Information Screen displays content to respondents without asking for an answer. Use this type for welcome messages, consent statements, instructions between sections, or thank-you pages. It helps structure the questionnaire and set expectations without adding to your response data.

## When to use this question type

- You want to show a welcome message or instructions before the first question.
- You need to display a consent statement or privacy notice.
- You want to divide the questionnaire into sections with transition screens.
- You want to end the survey with a thank-you or redirection message.

## How to add it

<Steps>
  <Step>
    In the questionnaire builder, click **Add questions**.
  </Step>
  <Step>
    Select **Information Screen** from the popup.
  </Step>
  <Step>
    The screen appears on the canvas. Click it to open the configuration panel and add your text, images, or formatting.
  </Step>
</Steps>

## Settings

| Setting | Description |
| --- | --- |
| Screen title | The headline respondents see. |
| Body text | The main content, which supports rich text formatting. |
| Image or media | An optional image, video, or file to display on the screen. |
| Button label | The text on the button that advances the respondent, for example, "Continue" or "I agree". |
| Auto-advance | Automatically moves to the next question after a set time. |

<Note>
  **Needs product verification:** Confirm whether "Background colour" and "Custom CSS" settings exist for this question type.
</Note>

## What respondents see

Respondents see a screen with a title, body text, and optionally an image or media file. They read the content and click a button to continue. If auto-advance is enabled, the screen moves on automatically after the set duration. No data is collected from this screen.

## Logic and piping

Information Screens do not collect data, so they cannot be used as conditions in logic. However, you can place them before or after logic branches to create structured flows. For full instructions on logic, see [Logic and branching](/questionnaire/logic-and-branching).

## Results in reporting

Information Screens do not produce response data. They appear in the questionnaire structure for reference but have no entries in the results dashboard or exports.

## Example use case

A market research agency places an Information Screen at the start of a survey with the title "Welcome to our study" and body text explaining the purpose, estimated duration, and confidentiality assurances. Respondents click "Begin survey" to proceed to the first question.
