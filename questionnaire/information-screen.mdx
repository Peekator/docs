## When to use this screen

Use an Information screen when you want to:

- Welcome respondents or introduce the survey.
- Explain a task before respondents answer questions.
- Add context between sections of a questionnaire.
- Show a thank you or next steps message.

## Add an Information screen

1. In the questionnaire builder, select **Add questions**.
2. Select **Information screen**.
3. Enter your message in the editor.
4. Select **Save question**.

## Create your message

Use the message editor to format your content. You can add:

- Bold, italic, underlined and strikethrough text.
- Headings, text alignment and lists.
- Text and highlight colours.
- Links, images, files and videos.

Keep the message focused and make any action respondents need to take clear.

## Add a screen title

In the settings panel, enable **Screen title** to add a title above the message. The title appears beside the Information screen icon.

Select **Make default for all info screens** if you want new Information screens to use the same title setting.

## Conditions

Use **Add conditional rule** under **Ask only if** to control whether the Information screen is shown, based on an earlier answer.

For more information, see [Logic and branching](https://chatgpt.com/c/6a9944be-99a0-83ed-acda-754df5c50a8c#).

## What respondents see

Respondents see your formatted message and select **Next** to continue. Information screens do not require a response.

## Results in reporting

Information screens do not collect answers, so they do not create results in reporting. You can still use them to guide respondents through different paths in the questionnaire.

## Example use case

Before a product evaluation section, add an Information screen that says:

> Next, we will ask about your experience with the product. Please consider your most recent use when answering the following questions.
