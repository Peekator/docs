An information screen displays rich text or HTML content to respondents without collecting any answer. Use it to introduce a section, provide context before a set of questions, show a consent statement, or display important instructions.

## Add an information screen

<Steps>
  <Step title="Click Add Question">
    In the questionnaire builder, click **Add Question** and select **Information Screen**.
  </Step>
  <Step title="Enter the content">
    Type or paste the HTML or rich text that respondents will read. This can include formatted text, links, or embedded images.
  </Step>
  <Step title="Optionally add a custom title">
    Enable **Show custom screen title** and enter the title text to display a heading above the content.
  </Step>
</Steps>

## Settings

| Setting | Description |
| --- | --- |
| **Content** | The HTML or rich text body displayed to respondents. Supports formatting, links, and inline media. |
| **Show custom screen title** | Display a custom heading above the content. |
| **Custom title** | The heading text shown when **Show custom screen title** is enabled. |

<Note>
  Information screens do not collect any data. They advance to the next screen when the respondent clicks the Continue button.
</Note>

## Common use cases

- Welcome message at the start of the survey
- Section dividers between topic blocks
- Consent or privacy notice before sensitive questions
- Instructions for a complex task
