Before setting translations, add a **Language single choice** question to the questionnaire. Add the languages you want to offer as answers.

<Info>
  An Instruction note is added automatically. You can edit it to give respondents additional guidance.
</Info>

## Set the survey’s main language

**English** is the default main language. The main language is the original version of the survey that translations are based on.

To change it:

1. Go to **Setup** → **Settings**.
2. Select **Main language of the survey**.
3. Choose the language to use as the main language.

## Configure the language question

In the **Language single choice** question:

1. Add the languages respondents can select.

<Note>
  Disable **Show flags** if you don't want a small country flag to appear next to each language in the survey.
</Note>

## Add translations

After adding the language question:

1. Open **Set more**.
2. Select **Set Translations**.
3. Choose the language you want to translate from the language tabs at the top.
4. Enter translations for each question, instruction note and answer option.
5. Select **Save settings for translations** when you are finished.

Translations are set separately for each language. Repeat the process for every language you have added.

### Translate manually

For each question, enter the translated question text in the **Question translation** field. Enter translated answer text beside each original answer.

If you leave a question, instruction note or answer field blank, it remains in the main-language form for respondents using that language.

<Tip>
  If a question includes an image or video that you want to translate, the quickest approach is to generate the translation with AI first, then make any necessary changes manually.
</Tip>

### Generate translations with AI

You can also use AI to create translations:

- Select **Translate all questions** to generate translations for the full survey.
- Enable **Translate only selected** to generate translations only for the questions you choose.

Review the generated text and edit it where needed before saving.

## Example

If your main language is English and a respondent selects French:

- Translated fields are shown in French.
- Any blank translation fields remain in English.
- If **Show flags** is enabled, the French option is shown with its flag in the language selector.
