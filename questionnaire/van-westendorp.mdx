Van Westendorp Price Sensitivity Meter uses four fixed price questions to map consumer perceptions of price and identify the acceptable price range for a product or service.

Respondents use sliders to indicate the price they consider too cheap, affordable, expensive, and too expensive. Plotting the cumulative responses reveals the acceptable price band, the point of marginal cheapness, and the point of marginal expensiveness.

## Add a Van Westendorp question

<Steps>
  <Step title="Click Add Question">
    In the questionnaire builder, click **Add Question** and select **Van Westendorp**.
  </Step>
  <Step title="Configure the price range">
    Set the minimum and maximum values for the sliders and choose the currency.
  </Step>
  <Step title="Review the fixed questions">
    The four sub-questions are pre-defined and appear in order. Edit the wording if needed to reference your specific product or service.
  </Step>
</Steps>

## Fixed sub-questions

Van Westendorp always uses these four questions in order. They cannot be removed or reordered:

1. What price would you consider as **"too low"** for this product / service?
2. What price would you consider as **"affordable"** for this product / service?
3. What price would you consider as **"expensive"** for this product / service?
4. What price would you consider as **"too expensive"** for this product / service?

## Settings

| Setting | Description |
| --- | --- |
| **Minimum value** | Lowest price value on the sliders. Default is `0`. |
| **Maximum value** | Highest price value on the sliders. Default is `100`. |
| **Step** | Slider increment. Default is `1`. |
| **Currency** | Currency symbol displayed next to slider values. Default is `EUR`. |
| **Decimal places** | Number of decimal places. Default is `2`. |

<Note>
  The default instruction shown to respondents is: "Using the sliders, indicate the price you consider too cheap, a good deal, starting to get expensive, and too expensive. Choose the amounts that feel right."
</Note>
