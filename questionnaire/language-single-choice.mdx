The language single choice question lets respondents select the language for the rest of the survey. Place it at the beginning of the questionnaire before any other questions so respondents can immediately switch to their preferred language.

<Note>
  After adding a language single choice question, you must set up translations under the **Set more** option in the questionnaire editor. Without translations, all subsequent questions will remain in the original language regardless of the respondent's selection.
</Note>

## Add a language single choice question

<Steps>
  <Step title="Click Add Question">
    In the questionnaire builder, click **Add Question** and select **Language Single Choice**.
  </Step>
  <Step title="Add language options">
    Each answer option is a language. Add one answer per supported language. Set the language code (for example, `en-GB`) and the display name shown to respondents.
  </Step>
  <Step title="Set translations">
    Open the **Set more** menu and configure translations for each language you added. This is required for the language switch to work.
  </Step>
</Steps>

## Settings

| Setting | Description |
| --- | --- |
| **Show flags** | Display a country flag icon next to each language name. Enabled by default. |
| **Shuffle questions inside the group** | Randomize the order of questions within the language group after a language is selected. |
| **Language options** | Each answer defines a language code (for example `en-GB`, `hr-HR`) and a display name. |

<Note>
  The default instruction shown to respondents is: "Select language of the survey."
</Note>
