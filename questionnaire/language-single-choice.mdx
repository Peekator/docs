A Language Single Choice question lets respondents choose which language they want to complete the survey in. This is typically placed at the very beginning of the questionnaire and controls which translated version of the survey the respondent sees.

## When to use this question type

- You are running a multilingual survey and want respondents to self-select their language.
- You want to give respondents control over their language preference rather than relying on browser settings or pre-assigned links.
- You need to capture language choice as a data point for analysis.

## How to add it

<Steps>
  <Step>
    In the questionnaire builder, click **Add questions**.
  </Step>
  <Step>
    Select **Language Single Choice** from the popup.
  </Step>
  <Step>
    The question appears on the canvas. Click it to open the configuration panel and choose which languages to offer.
  </Step>
</Steps>

## Settings

| Setting | Description |
| --- | --- |
| Question text | The label respondents see, for example, "Please select your language". |
| Available languages | The list of languages respondents can choose from. Only languages with completed translations are shown. |
| Default language | The pre-selected language, if any. |
| Mandatory | Requires a selection before the respondent can continue. |
| Display as dropdown | Shows languages in a dropdown instead of a radio button list. |

<Note>
  **Needs product verification:** Confirm whether "Auto-detect language" and "Redirect to language-specific URL" settings exist for this question type.
</Note>

## What respondents see

Respondents see a list or dropdown of available languages at the start of the survey. They select one option. After confirming, the rest of the questionnaire is displayed in their chosen language. If a language is not fully translated, fallback text may appear in the default language.

## Logic and piping

You can use the selected language in logic to show or hide later questions. For example, you might show culturally specific follow-up questions only to respondents who selected a particular language. For full instructions, see [Logic and branching](/questionnaire/logic-and-branching).

## Results in reporting

Results show the count and percentage of respondents who selected each language. This helps you understand the language composition of your sample and can be used to filter or weight other results.

## Example use case

A global consumer goods company runs a survey in English, Spanish, French, and German. The Language Single Choice question appears on the welcome screen. Respondents select Spanish and the entire questionnaire, including buttons and error messages, is shown in Spanish.
