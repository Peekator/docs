## When to use this question type

Use a Language single choice question when you need to:

- Run the same questionnaire in more than one language.
- Let each respondent choose their preferred survey language.
- Show the correct translated content after a language is selected.

## Add a Language single choice question

1. In the questionnaire builder, select **Add questions**.
2. Select **Language single choice**.
3. Select the languages you want to offer. Use search or **Select all** to find and add languages quickly.
4. Select **Confirm**. Each language is added as a separate answer choice.
5. Enter your question text and edit the **Instruction note** if needed.
6. Select **Save question**.

Although you can add several languages at once, respondents select one language.

You can remove a language from the answer list at any time.

## Set translations

After you add a Language single choice question, open **Set more** and select **Set Translations**.

Add translations for the question text, instruction notes, answer options and other questionnaire content. The language options you add to this question should match the translations you set up.

For more information, see [Questionnaire translations](https://chatgpt.com/c/6a9944be-99a0-83ed-acda-754df5c50a8c#).

## What respondents see

Respondents see the available languages and select one. The questionnaire then displays in the language you have set up for their selection.

## Results in reporting

Results show how many respondents selected each language and the percentage each language represents.

## Example use case

An organisation runs a questionnaire in English, Croatian and German. Respondents select their preferred language on the first screen, then complete the translated version of the questionnaire.
