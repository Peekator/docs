Quotas help you collect the required mix of respondents. For example, you may need a specific number of respondents in each age group, job role or customer segment.

## Set a quota

1. Select **Set Quota** in the upper-right corner.
2. Select **Add new quota**.
3. Select the question from the dropdown.
4. Enable each answer that needs a target.
5. Enter the target for each enabled answer.
6. Select **Save Quota**.

Use **Enable all answers** when every answer in the selected question needs a quota.

You can select **Add new quota** again to set quotas for another question.

## Example: age quotas

For a 500-response survey, you could set these targets for an age question:

| Answer | Quota |
| :-- | :-- |
| 18–34 | 35% |
| 35–54 | 40% |
| 55+ | 25% |

For a Single choice question, quota targets will normally total 100% or the total target number of responses.

## Use hidden variables for complex segments

Set a quota on a hidden variable when the group you need cannot be defined by one answer alone.

For example, you may need a quota for respondents who are both:

- senior decision-makers; and
- involved in purchasing software for their organisation.

First, create a hidden variable with those conditions. Then add a quota and select that hidden variable as the source.

This lets you set a target for a more complex group without creating a separate screener question.

For instructions on creating the group, see [Hidden variables](/questionnaire/hidden-variables).

## Quotas for Multiple choice questions

Multiple choice answers can overlap because respondents may select more than one option.

For example, a respondent may select both **Purchasing software** and **Managing IT systems**. They can therefore contribute to both enabled quotas.

This means that percentage quotas in a Multiple choice question may total more than 100%.

## See which questions have quotas

A question with a quota is marked with the **Quota** indicator in the questionnaire menu.

Use this indicator to check which questions are controlling quota targets while you build or review the questionnaire.

## Monitor quota results

Questions with quotas are marked as **Quota** in Results.

The graph for a quota question is based on the quota targets you set, rather than the actual number of respondents alone. It shows progress against each target, for example:

- `0 / 100` means no responses have yet been counted towards a target of 100;
- `65 / 100` means 65 responses have been counted towards that target.

Review quota progress throughout fieldwork to see which groups are filling more slowly.
