Constant sum questions ask respondents to distribute a fixed total value across a set of items. Because the total is fixed, respondents must make explicit trade-offs, producing precise ratios of relative importance or preference.

Use this type for budget allocation exercises, attribute importance weighting, or any scenario where proportional relationships matter.

## Add a constant sum question

<Steps>
  <Step title="Click Add Question">
    In the questionnaire builder, click **Add Question** and select **Constant Sum**.
  </Step>
  <Step title="Enter question text">
    Describe what respondents should distribute, for example: `Distribute 100 points across the following product features based on importance to you.`
  </Step>
  <Step title="Add items">
    Add each item as a sub-question. Respondents will enter a number for each item.
  </Step>
  <Step title="Set the total to distribute">
    Enter the fixed total respondents must allocate across all items.
  </Step>
</Steps>

## Settings

| Setting | Description |
| --- | --- |
| **Items** | Add, edit, remove, or reorder the items respondents allocate to. Each item is a sub-question. |
| **Value to distribute** | The fixed total respondents must allocate across all items (for example, `100` for a 100-point allocation). |
| **Show as percentage** | Display values as percentages rather than raw numbers. |
| **Shuffle answers** | Randomize the order of items for each respondent. |
| **Minimum value** | The minimum value a respondent can assign to any single item. |
| **Maximum value** | The maximum value a respondent can assign to any single item. |
| **Step** | The increment for each input. For example, a step of `5` only allows multiples of 5. |
| **Currency** | Display a currency label next to each value. |

<Note>
  Slider mode is no longer available. All constant sum questions use numeric input.
</Note>
