A Constant Sum question asks respondents to allocate a fixed number of points, percentages, or units across several options. The sum of their allocations must equal the specified total. This method forces trade-offs and reveals the relative importance or share of preference respondents assign to each item.

## When to use this question type

- You want respondents to show relative importance by distributing a fixed budget or percentage.
- You need to simulate realistic trade-offs, such as budget allocation or time spent.
- You want data that sums to 100 per cent or a fixed total for easy comparison.

## How to add it

<Steps>
  <Step>
    In the questionnaire builder, click **Add questions**.
  </Step>
  <Step>
    Select **Constant Sum** from the popup.
  </Step>
  <Step>
    The question appears on the canvas. Click it to open the configuration panel and add items, set the total, and configure validation.
  </Step>
</Steps>

## Settings

| Setting | Description |
| --- | --- |
| Question text | The label respondents see. |
| Items | The list of options respondents allocate points to. |
| Total to allocate | The fixed sum respondents must distribute, for example, 100 points or 10 hours. |
| Unit label | The label shown next to inputs, for example, "%", "points", or "hours". |
| Minimum per item | The lowest allocation allowed for any single item. |
| Maximum per item | The highest allocation allowed for any single item. |
| Mandatory | Requires the total to be reached before the respondent can continue. |
| Randomise items | Shuffles the order of items for each respondent. |

<Note>
  **Needs product verification:** Confirm whether "Auto-balance remaining" and "Allow decimal allocations" settings exist for this question type.
</Note>

## What respondents see

Respondents see a list of items, each with a numeric input field. They type a number for each item. A running total shows how much they have allocated and how much remains. The "Next" button remains disabled until the sum equals the required total, if mandatory.

## Logic and piping

You can use the allocation values for individual items in logic to show or hide later questions. For example, if a respondent allocates more than 50 per cent to one item, you can branch to a follow-up about why that item is so important. For full instructions, see [Logic and branching](/questionnaire/logic-and-branching).

## Results in reporting

Results appear as a table showing the average allocation, minimum, maximum, and total for each item. A stacked bar chart visualises the distribution. Because allocations sum to a fixed total, averages can be compared directly across items and segments.

## Example use case

A media company asks, "You have 100 points to allocate across these news categories. How important is each to you?" with items for Politics, Sports, Entertainment, Technology, and Health. The results show that Technology receives the highest average allocation, guiding content strategy.
