A Ranking question asks respondents to arrange a list of items in order of preference, importance, or priority. This reveals not just which items are liked, but how they compare to one another, giving you richer preference data than a simple multiple choice question.

## When to use this question type

- You want to understand the relative priority of features, brands, or messages.
- You need to identify a winner when multiple options are popular.
- You want to force trade-offs rather than letting respondents select everything.

## How to add it

<Steps>
  <Step>
    In the questionnaire builder, click **Add questions**.
  </Step>
  <Step>
    Select **Ranking** from the popup.
  </Step>
  <Step>
    The question appears on the canvas. Click it to open the configuration panel and add the items to be ranked.
  </Step>
</Steps>

## Settings

| Setting | Description |
| --- | --- |
| Question text | The label respondents see. |
| Items to rank | The list of options respondents will order. |
| Mandatory | Requires all items to be ranked before the respondent can continue. |
| Randomise items | Shuffles the order of items for each respondent. |
| Rank all | Requires respondents to rank every item, not just a subset. |
| Number to rank | Limits ranking to a specific number of items if not all need to be ranked. |

<Note>
  **Needs product verification:** Confirm whether "Reverse rank" and "Tie allowed" settings exist for this question type.
</Note>

## What respondents see

Respondents see a list of items, often with drag handles or numbered positions. They drag items into order or select a rank for each item. If "Rank all" is enabled, every item must be placed before they can continue. A counter may show progress.

## Logic and piping

You can use the top-ranked item or the rank of a specific item in logic to show or hide later questions. For example, if a respondent ranks "Price" first, you can branch to a price sensitivity question. For full instructions, see [Logic and branching](/questionnaire/logic-and-branching).

## Results in reporting

Results appear as a ranking table showing the average rank, first-place count, and distribution of positions for each item. A chart may show the percentage of respondents who ranked each item in each position. This makes it easy to identify clear winners and losers.

## Example use case

A retailer asks, "Please rank the following factors in order of importance when choosing an online store: Price, Delivery speed, Product range, Return policy, Customer reviews." The results show that Delivery speed and Price are the top two drivers for most customers.
