Open-end questions give respondents a text field to answer in their own words. Use this format to capture qualitative insights, detailed feedback, and unscripted opinions that structured questions cannot provide.

## Add an open-end question

<Steps>
  <Step title="Click Add Question">
    In the questionnaire builder, click **Add Question** and select **Open-End**.
  </Step>
  <Step title="Enter question text">
    Write a prompt that invites a free-text response, for example: `What could we do to improve your experience?`
  </Step>
</Steps>

## Settings

| Setting | Description |
| --- | --- |
| **Mandatory answer** | Require a response before the respondent can proceed. Enabled by default. |
| **Show as single line** | Display a single-line text box instead of a multi-line textarea. Useful for short, focused answers like names or codes. |
| **Answer validation** | Validate the response against a list of allowed values. Enter one acceptable answer per line in the validation field. |
| **Show large transcribe design** | Show an expanded transcription interface for longer audio-to-text workflows. |
| **Save audio files** | Record and save the respondent's audio input alongside the text response. |

<Note>
  The default instruction shown to respondents is: "Please type your answer below."
</Note>

<Tip>
  Open-end responses are processed by Peekator's AI Analysis features, which identify recurring themes, sentiment, and key topics across all submissions. See [AI Analysis](/ai-analysis/overview).
</Tip>
