An Open End question gives respondents a single-line text field to type a free-text answer. Use this type when you want unfiltered, qualitative responses in the respondent's own words, such as feedback, explanations, or spontaneous brand recall.

## When to use this question type

- You want verbatim responses rather than pre-defined options.
- You need to capture reasons, opinions, or suggestions in the respondent's own words.
- You want to identify themes or use AI auto-coding to categorise open-ended responses.

## How to add it

<Steps>
  <Step>
    In the questionnaire builder, click **Add questions**.
  </Step>
  <Step>
    Select **Open End** from the popup.
  </Step>
  <Step>
    The question appears on the canvas. Click it to open the configuration panel and edit the question text and validation rules.
  </Step>
</Steps>

## Settings

| Setting | Description |
| --- | --- |
| Question text | The label respondents see. |
| Placeholder text | Hint text shown inside the empty input field. |
| Mandatory | Requires text input before the respondent can continue. |
| Minimum characters | Sets the shortest acceptable response length. |
| Maximum characters | Sets the longest acceptable response length. |
| Validate as email | Restricts input to a valid email format. |
| Validate as URL | Restricts input to a valid URL format. |

<Note>
  **Needs product verification:** Confirm whether "Multi-line textarea" and "Spell check" settings exist for this question type.
</Note>

## What respondents see

Respondents see a single-line text input field below the question text. They type their answer. If minimum or maximum character limits are set, a counter may show progress. The "Next" button remains disabled until the mandatory requirement and any validation rules are met.

## Logic and piping

You can use the presence or content of an open-ended response in logic to show or hide later questions. For example, if a respondent leaves the field empty, you can skip a follow-up. For full instructions, see [Logic and branching](/questionnaire/logic-and-branching).

## Results in reporting

Responses appear as a list of verbatim answers. You can filter, search, and export them for qualitative analysis. If AI auto-coding is enabled, responses are automatically categorised into named themes with counts and percentages.

## Example use case

A cosmetics brand asks, "What is the first word that comes to mind when you think of our brand?" The verbatim responses are auto-coded by AI into themes such as "Natural", "Luxury", and "Expensive" to guide messaging strategy.
