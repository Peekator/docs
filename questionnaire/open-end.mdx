## When to use an Open-end question

- You want detailed feedback in respondents’ own words.
- You need to explore reasons, opinions or experiences.
- You want to identify themes through AI auto-coding.

## Add an Open-end question

1. In the Questionnaire builder, select **Add question**.
2. Select **Open-end**.
3. Enter your question text.
4. An **Instruction note** is added automatically. Edit it if needed.

## Configure the response

Select **See more** in the **Settings** panel to view all settings.

| Setting | What it means |
| :-- | :-- |
| Save audio files to the server | Saves the original voice recording. Turn this off if you want to keep only the transcript. |
| Show large transcribe design | Shows respondents a larger layout for recording and reviewing their voice transcript. |
| Show as single line | Displays a single-line text field instead of a larger text area. |
| Answer is mandatory | Requires respondents to provide an answer before continuing. |
| Enable answer validation | Requires the respondent’s text to match the accepted answer you add in the questionnaire. |
| Skip if no query string | Skips the question if the specified query string is not available. |
| Query string name | Enter the query string used in your survey link. |

## Voice responses

Respondents can record an answer instead of typing it. Peekator automatically creates a transcript.

Choose whether to save the original recording:

- Enable **Save audio files to the server** to keep both the recording and transcript.
- Disable it to keep the transcript only.

## Add conditions

Use **Add conditional rule** in the **Ask only if** section to control whether respondents see the question.

For full instructions, see [Logic and branching](https://chatgpt.com/c/6a9944be-99a0-83ed-acda-754df5c50a8c#).

## What respondents see

Respondents can enter a free-text answer or record a voice response.

If you enable answer validation, their typed answer must match the accepted answer before they can continue.

## Analyse answers with AI auto-coding

Open-end responses can be automatically coded into themes and categories.

1. Open the question in reporting.
2. Select **Add next AI auto-code**.
3. Review the category set created from the responses.
4. Select a category to view its coded responses.

You can use multiple category sets to analyse the same question from different perspectives.

## Review and edit coding

Use the reporting tools to review and refine the results:

- **View all**: view all responses in the selected category.
- **Edit categories**: rename, add or remove categories.
- **Edit answers**: review or update coded answers.
- **Delete all**: remove the current coding results.

You can switch between percentages and response counts.

## Example

Ask: “What is the best advice you have ever received?”

Use AI auto-coding to identify themes such as:

- Advice and sayings
- Financial advice
- Relationships
- Personal growth
