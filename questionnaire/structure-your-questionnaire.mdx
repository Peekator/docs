Peekator provides two main structural features to help you organise and reuse questionnaire content: sections for grouping questions, and cloning to copy an entire questionnaire from another survey.

## Sections

Sections (the **CategoryQuestion** type) let you group related questions visually within the questionnaire canvas. They are useful for long surveys or when you want to organise questions by topic.

### How to add a section

<Steps>
  <Step title="Open Add questions">
    Click **Add questions** in the questionnaire menu to open the question type selector.
  </Step>
  <Step title="Select Section">
    Choose the section or category question type and place it on the canvas.
  </Step>
  <Step title="Add questions into the section">
    Drag or add questions inside the section. Sections can be collapsed to simplify the view while you work.
  </Step>
</Steps>

### When to use sections

- Long surveys with many questions: break the flow into clear topic groupings
- Topic-based questionnaires: keep demographic, product, or brand questions together
- Collaborative editing: make it easier for teammates to navigate the canvas

## Clone questionnaire

The **Clone questionnaire** feature copies all questions from another survey into the current one. You can access it from the empty state on the questionnaire canvas when no questions exist yet.

### How to clone a questionnaire

<Steps>
  <Step title="Start from an empty canvas">
    Open a survey in Editing status with no questions added yet.
  </Step>
  <Step title="Click Clone questionnaire">
    Select **Clone questionnaire** from the empty state prompt.
  </Step>
  <Step title="Choose the source survey">
    Pick the survey you want to copy from. All questions are copied into the current survey.
  </Step>
</Steps>

<Warning>
  Cloning replaces any existing questions in the current survey. Make sure the canvas is empty or that you are prepared to overwrite current content.
</Warning>

<Note>
  **Needs product verification:** whether Clone questionnaire appends or replaces existing questions.
</Note>

## Test before launch

Whenever you restructure a questionnaire, always preview and test the full flow before launching. Use the **Preview survey** button and the test link to verify that sections display correctly and cloned questions behave as expected.
