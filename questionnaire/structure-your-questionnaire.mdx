## Sections

Sections visually group related questions on the questionnaire canvas. They are useful for long surveys or surveys that cover several topics.

### Add a section

1. In the questionnaire builder, open **Options**.
2. Select **Add Section**.
3. Enter a title for the section.

In the section settings, you can choose whether the section title is visible in the Dashboard.

### When to use sections

Use sections to:

- break a long questionnaire into clear topic areas;
- keep related questions together, such as demographics, product usage or brand perception; and
- make the questionnaire easier for collaborators to review and edit.

## Clone a questionnaire

Clone a questionnaire when you want to use an existing survey as a starting point.

You can start the clone flow in either of these ways:

- In an empty questionnaire, select **Clone questionnaire** in the centre of the canvas.
- Open **Options**, then select **Clone Questionnaire**.

1. Select **Clone questionnaire**.
2. In the **Clone questionnaire from** window, choose the source project.
3. Select the questionnaire you want to copy.
4. Review the copied questionnaire and make any necessary changes before launch.

<Warning>
  Cloning replaces any existing questions in the current survey. Make sure the canvas is empty or that you are prepared to overwrite current content.
</Warning>
