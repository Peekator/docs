Multiple choice questions let respondents select one or more answers from a predefined list. Use this type when you want to allow several valid answers, such as selecting all products a customer uses or all challenges they face.

<Tip>
  Use multiple choice when more than one answer can reasonably apply. Use [single choice](/questionnaire/single-choice) when exactly one answer is correct or expected.
</Tip>

## Add a multiple choice question

<Steps>
  <Step title="Click Add Question">
    In the questionnaire builder, click **Add Question** and select **Multiple Choice**.
  </Step>
  <Step title="Enter question text">
    Type your question. For example: `Which of the following products do you currently use?`
  </Step>
  <Step title="Add answer options">
    Click **Add option** for each answer choice.
  </Step>
</Steps>

## Settings

| Setting | Description |
| --- | --- |
| **Include "Other"** | Adds a free-text "Other (please specify):" option at the end of the list. |
| **Screenout on "Other"** | Respondents who select Other are screened out. Only available when Include "Other" is enabled. |
| **Shuffle answers** | Randomizes the order of answer options on each load to prevent position bias. |
| **Number of columns** | Display options across multiple columns. Default is `1`. |
| **Limit answer count** | Restrict how many options a respondent can select. Set **Minimum required answers** and **Maximum allowed answers**. For example, set maximum to `3` for "Choose your top 3". |
| **Show results as percentage** | Display results as percentages instead of absolute counts in reporting. |
| **Answers are events** | Treat each answer selection as an event for tracking purposes. |
| **Assign points** | Assign a point value to each answer option for scoring or weighting. |
| **Conditional rule on answers** | Apply conditional logic based on the answers selected. |

<Note>
  The default instruction shown to respondents is: "Select all that apply."
</Note>
