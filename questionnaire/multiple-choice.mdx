## When to use Multiple choice

- Respondents may need to select more than one answer.
- You want to understand combinations of preferences or behaviours.
- You want to compare each selected answer in reporting.

## Add a Multiple choice question

1. In the Questionnaire builder, select **Add question**.
2. Select **Multiple choice**.
3. Enter your question text.
4. An **Instruction note** is added automatically. Edit it if you need to give respondents additional guidance.
5. **Type** or **paste** your answer choices into the first answer field. 
6. Select **Add answer** to add further choices manually, or drag answers to change their order.

<Tip>
  You can **paste multiple answers** into the first field. Peekator automatically separates them into individual items.
</Tip>

## Add conditions

You can add conditions to either the whole question or individual answer choices.

### Condition a question

Use **Add conditional rule** in the **Ask only if** section to control whether respondents see the whole question. For example, show a question only to respondents who selected a particular answer earlier in the survey.

### Condition an answer

Use **Conditional rule on answer** to control whether a specific answer choice appears. For example, show an answer only when it is relevant to a respondent’s earlier response.

For full instructions and examples, see [Logic and branching](#).

## What respondents see

Respondents see a list of answer choices and can select more than one.

If you set answer limits, respondents must select within the minimum and maximum number specified. If you include an **Other** answer, they can enter their own response after selecting it.

## Results in reporting

In reporting, you can see how many respondents selected each answer and the percentage each answer represents.

As respondents can select more than one answer, percentages may add up to more than 100%.

## Example

Ask: “Which of the following streaming genres do you watch at least once a week?”

Answers: Drama, Comedy, Documentary, Reality and Other.
