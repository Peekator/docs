A Multiple Choice question lets respondents select one or more answers from a list of options. Use this type when you want to capture all relevant choices, such as products used, features liked, or interests held.

## When to use this question type

- You want respondents to select every option that applies, not just one.
- You need to understand combinations of preferences or behaviours.
- You plan to analyse overlap between choices, such as which features are used together.

## How to add it

<Steps>
  <Step>
    In the questionnaire builder, click **Add questions**.
  </Step>
  <Step>
    Select **Multiple Choice** from the popup.
  </Step>
  <Step>
    The question appears on the canvas. Click it to open the configuration panel and edit the text and options.
  </Step>
</Steps>

## Settings

| Setting | Description |
| --- | --- |
| Question text | The label respondents see. |
| Answer options | The list of choices. Click to add, reorder, or remove options. |
| Allow "Other" option | Adds an "Other" choice with a free-text field. |
| Mandatory | Requires at least one selection before the respondent can continue. |
| Randomise options | Shuffles the order of choices for each respondent. |
| Minimum selections | Sets the lowest number of options a respondent must choose. |
| Maximum selections | Sets the highest number of options a respondent can choose. |
| Exclusive option | Marks one choice (for example, "None of the above") so selecting it deselects all other choices. |

<Note>
  **Needs product verification:** Confirm whether "Allow not sure" and "Display as dropdown" settings exist for this question type.
</Note>

## What respondents see

Respondents see a vertical list of checkboxes or tiles. They can tick multiple options. If minimum or maximum limits are set, a counter shows how many they have selected. The "Next" button remains disabled until the mandatory requirement is met.

## Logic and piping

You can use Multiple Choice answers in logic to show or hide later questions based on whether a specific option was selected. For full instructions, see [Logic and branching](/questionnaire/logic-and-branching).

## Results in reporting

Results appear as a stacked bar chart or table showing the count and percentage for each option. Respondents can select multiple options, so percentages typically sum to more than 100 per cent. Overlap between choices can be analysed in cross-tabulations.

## Example use case

A streaming service asks, "Which of the following genres do you watch at least once a week?" with options for Drama, Comedy, Documentary, Reality, and Other. The results reveal which genres are most popular and which combinations are common.
