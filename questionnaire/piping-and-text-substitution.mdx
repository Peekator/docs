## Piping

You can pipe from:

- an earlier **Multiple choice** question; or
- a **hidden variable**.

When piping from a Multiple choice question, Peekator pipes every option the respondent selected. You cannot choose only some of their selected options.

For example, if a respondent selects _Product quality_, _Customer service_ and _Price_, all three can appear in the next question.

<Tip>
  To show only selected options in specific circumstances, use [Conditions on answers](/questionnaire/logic-and-branching) instead.
</Tip>

Piping does not include text entered in an Other answer.

## Pipe answers into a question

1. Open the question that should receive the piped answers.
2. Select **Pipe answers**.
3. Choose the earlier **Multiple choice** question or hidden variable to use as the source.
4. Confirm your selection.

The next step depends on the type of question receiving the piped answers.

<Note>
  Preview and test the questionnaire after setting up piping, especially when the source question allows several selections.
</Note>

## Text substitution

Use text substitution when an earlier response should appear inside another piece of text. You can add the value to:

- question text;
- an instruction note;
- an answer option; or
- another text field in the questionnaire.

For example, if a respondent selects **Company Ltd** as their employer, you can ask:

> How do you find working at Company Ltd?

### Set up text substitution

1. Select **Set more**.
2. Select **Set Text Substitution**.
3. Choose the source question and answer.
4. Peekator automatically fills **Value to replace** and **Text to replace**.
5. Copy the automatically generated **Text to replace** into the target question, instruction note or answer option.
6. Save your changes.

For a closed question with several possible answers, add a substitution row for each answer you want to replace. For an open-end question, Peekator automatically uses the text entered by the respondent.

<Warning>
  Copy Text to replace exactly as it appears. Do not add or remove spaces, letters or symbols.When to use each feature
</Warning>
