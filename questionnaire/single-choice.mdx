A Single Choice question asks respondents to pick exactly one answer from a list of options. This is one of the most common question types in Peekator and works well for demographic questions, brand preference, or any scenario where you need a clear, mutually exclusive selection.

## When to use this question type

- You need respondents to select one answer only, such as a primary brand or favourite feature.
- You want clean, easy-to-analyse data without overlap between choices.
- You plan to use the answer as a condition for logic or branching later in the questionnaire.

## How to add it

<Steps>
  <Step>
    In the questionnaire builder, click **Add questions**.
  </Step>
  <Step>
    Select **Single Choice** from the popup.
  </Step>
  <Step>
    The question appears on the canvas. Click it to open the configuration panel and edit the text and options.
  </Step>
</Steps>

## Settings

| Setting | Description |
| --- | --- |
| Question text | The label respondents see. |
| Answer options | The list of choices. Click to add, reorder, or remove options. |
| Allow "Other" option | Adds an "Other" choice with a free-text field. |
| Mandatory | Requires a selection before the respondent can continue. |
| Randomise options | Shuffles the order of choices for each respondent. |
| Exclusive option | Marks one choice (for example, "None of the above") so selecting it deselects all other choices. |

<Note>
  **Needs product verification:** Confirm whether "Allow not sure" and "Display as dropdown" settings exist for this question type.
</Note>

## What respondents see

Respondents see a vertical list of radio buttons or tiles. They click one option. If "Other" is enabled, a text box appears when that option is selected. The "Next" button remains disabled until a choice is made if the question is mandatory.

## Logic and piping

Single Choice answers are ideal for logic and branching. You can show or hide later questions based on which option a respondent selects. For full instructions, see [Logic and branching](/questionnaire/logic-and-branching).

## Results in reporting

Results appear as a bar chart or pie chart showing the count and percentage for each option. If "Other" responses were collected, they are listed in a separate table or exported for manual review.

## Example use case

A consumer electronics brand asks, "Which smartphone brand do you currently use?" with options: Apple, Samsung, Google, Other. The answer is used later to branch to brand-specific follow-up questions.
