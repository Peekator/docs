## When to use a Quadrant Matrix

Use this question when you want respondents to position an item, concept or brand between two opposing scales.

For example:

- map a brand from _traditional_ to _modern_ and _affordable_ to _premium_;
- assess an experience from _easy_ to _difficult_ and _useful_ to _not useful_; or
- understand where a concept sits between two viewpoints.

## Add a Quadrant Matrix question

1. In the questionnaire builder, select **Add questions**.
2. Choose **Quadrant Matrix**.
3. Enter the question text.
4. Define the labels at each end of the X and Y axes.

An **Instruction note** is added automatically. You can edit it to give respondents additional guidance.

## Configure the axes

Choose clear, opposing labels. For example:

| Axis | Labels |
| :-- | :-- |
| X axis | Traditional — Modern |
| Y axis | Affordable — Premium |

## Configure the scale

In **Settings**, set the numeric range for each axis:

| Setting | Description |
| :-- | :-- |
| **Min X value** | Sets the lowest value on the X axis. |
| **Max X value** | Sets the highest value on the X axis. |
| **Min Y value** | Sets the lowest value on the Y axis. |
| **Max Y value** | Sets the highest value on the Y axis. |

## Conditional logic

Under **Ask only if**, select **Add conditional rule** to control whether the entire Constant sum question is shown, based on an earlier answer.

For more information, see [Logic and branching](/questionnaire/logic-and-branching).

## What respondents see

Respondents see a chart with your X and Y axis labels. They place their answer at the point that best represents their view across both dimensions.

For example, a respondent may place a brand towards _Modern_ and _Premium_.

## Results in reporting

Results use respondents’ X and Y placements to show where answers fall across the matrix.

Use the results to identify clusters of opinion, compare which quadrants receive the most responses and understand the overall position of the item being assessed.

## Example use case

A retailer asks customers to position its brand between _Affordable_ and _Premium_ on one axis, and _Traditional_ and _Modern_ on the other.

The results show how customers perceive the brand and whether its intended positioning matches their experience.
