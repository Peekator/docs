Quadrant matrix questions present respondents with a two-axis grid and ask them to drag items to the position that best matches their perception. Use this type for importance vs. satisfaction mapping, risk vs. impact assessments, or brand positioning exercises.

Results display the average position of each item across all respondents as a perceptual map.

## Add a quadrant matrix question

<Steps>
  <Step title="Click Add Question">
    In the questionnaire builder, click **Add Question** and select **Quadrant Matrix**.
  </Step>
  <Step title="Enter question text">
    Write the prompt respondents see, for example: `Plot each feature on the matrix based on how you feel about it.`
  </Step>
  <Step title="Label the axes">
    Set labels for each end of both axes (left, right, top, bottom).
  </Step>
  <Step title="Add items to plot">
    Add each item as a sub-question. Respondents will drag each item onto the matrix.
  </Step>
</Steps>

## Settings

| Setting | Description |
| --- | --- |
| **X-axis left label** | Label for the left end of the horizontal axis. |
| **X-axis right label** | Label for the right end of the horizontal axis. |
| **Y-axis bottom label** | Label for the bottom end of the vertical axis. |
| **Y-axis top label** | Label for the top end of the vertical axis. |
| **X minimum / X maximum** | Numeric range for the horizontal axis. |
| **Y minimum / Y maximum** | Numeric range for the vertical axis. |
| **Items** | The items respondents position on the matrix. Add as sub-questions. |

<Note>
  The default instruction shown to respondents is: "Plot on the matrix how you feel between both dimensions."
</Note>

<Tip>
  Use a clear axis label pair that makes the trade-off obvious, for example "Important" vs "Not important" on one axis and "Satisfied" vs "Unsatisfied" on the other.
</Tip>
