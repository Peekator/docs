## When to use this question type

- You want respondents to rate several items on the same scale.
- You need to compare responses across related statements.
- You want to keep a set of related questions together.

## How to add it

1. In the Questionnaire builder, select **Add question**.
2. Select **Grid**.
3. Enter your question text.
4. An **Instruction note** is added automatically. Edit it if needed, for example to say “Select one option per row”.
5. Add your **Rows**. These are the statements or items respondents will evaluate.
6. Add your **Columns**. These are the response choices or scale points.

<Tip>
  You can **paste multiple rows** or **columns** into the first field. Peekator automatically separates them into individual items.
</Tip>

## Use sections

You can group related rows into sections.

Open the row’s answer settings and select **Make this answer a Section**. The row becomes a heading for the rows beneath it.

## Add conditions and piping

Use **Add conditional rule** in the **Ask only if** section to control whether respondents see the whole Grid.

Use **Conditional rule on answer** to add conditions to individual Grid items.

Select **Pipe answers** to use answers from earlier questions in your Grid.

For full instructions, see [Logic and branching](#) and [Piping answers](#).

## What respondents see

By default, respondents see rows on the left and answer choices across the top of a table.

With **Single choice**, they select one answer for each row. With **Multiple choice**, they can select more than one answer per row.

If **Always show as mobile version** is enabled, each row appears as a separate statement rather than part of a table.

## Results in reporting

Reporting displays the response distribution for every row and column in a table. You can switch between percentages and response counts.

## Example

Ask: “To what extent do you agree with the following statements?”

Rows:

- The website is easy to use.
- The information is clear.
- I would recommend this service.

Columns:

- Strongly disagree
- Disagree
- Neutral
- Agree
- Strongly agree
