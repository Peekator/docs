A Grid question presents a matrix of rows and columns. Respondents rate or evaluate several items using the same scale, which keeps the questionnaire compact and makes comparisons easy. This is ideal for attitude statements, feature importance, or satisfaction ratings.

## When to use this question type

- You want respondents to rate several items on the same scale, such as importance or agreement.
- You need to compare scores across items in a single view.
- You want to reduce questionnaire length by grouping related ratings into one question.

## How to add it

<Steps>
  <Step>
    In the questionnaire builder, click **Add questions**.
  </Step>
  <Step>
    Select **Grid** from the popup.
  </Step>
  <Step>
    The question appears on the canvas. Click it to open the configuration panel and add rows, columns, and labels.
  </Step>
</Steps>

## Settings

| Setting | Description |
| --- | --- |
| Question text | The label respondents see above the grid. |
| Rows | The items respondents evaluate, for example, product features or statements. |
| Columns | The scale or response options, for example, "Strongly disagree" to "Strongly agree". |
| Mandatory | Requires a selection for every row before the respondent can continue. |
| Randomise rows | Shuffles the order of rows for each respondent. |
| Reverse scale | Flips the column order for some respondents to reduce bias. |
| Force response per row | Ensures every row receives an answer. |

<Note>
  **Needs product verification:** Confirm whether "Column labels" and "N/A column" settings exist for this question type.
</Note>

## What respondents see

Respondents see a table with rows on the left and column headers across the top. They select one cell per row, usually by clicking a radio button. If the question is mandatory, they must complete every row before continuing.

<Warning>
  Grid questions involve multiple rows and validation rules. Always preview and test the full questionnaire before launching to ensure rows, columns, and mandatory rules behave as expected.
</Warning>

## Logic and piping

You can use answers from individual rows in logic to show or hide later questions. For example, if a respondent rates "Customer support" as "Very dissatisfied", you can branch to a follow-up question. For full instructions, see [Logic and branching](/questionnaire/logic-and-branching).

## Results in reporting

Results appear as a matrix table showing the distribution of responses for each row. You can also view average scores per row if the columns are numeric or ordered scales. Cross-tabs let you compare row ratings by respondent segment.

## Example use case

A hotel chain asks guests to rate five service aspects (check-in, room cleanliness, staff friendliness, amenities, value) on a scale from "Very dissatisfied" to "Very satisfied". The grid format keeps the questionnaire short and produces a clear satisfaction profile.
