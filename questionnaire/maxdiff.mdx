MaxDiff (Maximum Difference Scaling) forces respondents to make trade-offs by choosing the most and least preferred item from small sets. This produces a ranked preference score for each item that is more reliable than rating scales.

Use MaxDiff when you need to prioritize features, rank brand attributes, or test which messages resonate most with your audience.

## Add a MaxDiff question

<Steps>
  <Step title="Click Add Question">
    In the questionnaire builder, click **Add Question** and select **MaxDiff**.
  </Step>
  <Step title="Enter question text">
    Type the prompt respondents see before each set of items.
  </Step>
  <Step title="Add items">
    Add each item (feature, attribute, or message) respondents will evaluate as an answer option.
  </Step>
  <Step title="Configure set size and repetitions">
    Set how many items appear per screen and how many times each item should appear across all sets.
  </Step>
</Steps>

## Settings

| Setting | Description |
| --- | --- |
| **Items** | The list of items respondents evaluate. Add as many as needed as answer options. |
| **Shuffle items** | Randomize the order items appear across sets. |
| **Items per screen** | Number of items shown in each comparison set. Set to `0` to show all items on one screen. |
| **Times to show each item** | Target number of times each item appears across all sets shown to a respondent. |

<Note>
  The two response columns are always **Worst** and **Best** and cannot be changed. The default instruction is: "You will see multiple sets of attributes. For each set, please select one attribute that is least valuable and one that is most valuable."
</Note>
