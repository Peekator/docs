A MaxDiff question, also known as best-worst scaling, asks respondents to choose the most important and least important items from a small subset. By repeating this across multiple sets, MaxDiff produces a reliable ranking of all items based on relative importance, avoiding the bias that occurs when respondents rate everything highly.

## When to use this question type

- You want to measure the relative importance or preference of many items.
- You need to force trade-offs rather than allowing respondents to rate everything as important.
- You want statistically robust preference scores that can be compared across segments.

## How to add it

<Steps>
  <Step>
    In the questionnaire builder, click **Add questions**.
  </Step>
  <Step>
    Select **MaxDiff** from the popup.
  </Step>
  <Step>
    The question appears on the canvas. Click it to open the configuration panel and add items, set the number of items per set, and configure the number of sets.
  </Step>
</Steps>

## Settings

| Setting | Description |
| --- | --- |
| Items | The full list of attributes, features, or statements to evaluate. |
| Items per set | The number of items shown in each choice task, typically 4 or 5. |
| Number of sets | How many tasks each respondent completes. |
| Balanced design | Ensures each item appears an equal number of times across sets. |
| Mandatory | Requires a best and worst choice in every set before the respondent can continue. |
| Randomise items within sets | Shuffles the order of items within each task. |

<Note>
  **Needs product verification:** Confirm whether "Anchor item" and "Prohibited pairs" settings exist for this question type.
</Note>

## What respondents see

Respondents see a small set of items, typically 4 to 5, with two selection columns: "Most important" and "Least important". They select one item in each column. This repeats for several sets. The design ensures each respondent sees a balanced sample of all items.

<Warning>
  MaxDiff questions involve complex experimental design and validation. Always preview and test the full questionnaire before launching to ensure sets are balanced, items display correctly, and best/worst selections are enforced.
</Warning>

## Logic and piping

You can use aggregate MaxDiff scores or responses to specific sets in logic to show or hide later questions. For example, if a respondent consistently selects a feature as most important, you can branch to a pricing question about that feature. For full instructions, see [Logic and branching](/questionnaire/logic-and-branching).

## Results in reporting

Results show utility scores for each item, indicating relative importance on a common scale. A ranking table and bar chart display the scores. Cross-tabs let you compare preferences across respondent segments. Raw choice data is available for advanced statistical modelling.

## Example use case

A software company wants to prioritise 12 new features. It runs a MaxDiff with 5 items per set and 6 sets per respondent. The results show that "Offline mode" and "Two-factor authentication" have the highest utility scores, guiding the product roadmap.
