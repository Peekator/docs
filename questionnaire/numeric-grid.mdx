Numeric grid questions display a table where each cell receives a numeric input. Respondents type a number for each row/column combination. Use this type for budget allocation, volume estimates, or any multi-item numeric data collection.

## Add a numeric grid question

<Steps>
  <Step title="Click Add Question">
    In the questionnaire builder, click **Add Question** and select **Numeric Grid**.
  </Step>
  <Step title="Enter question text">
    Type the prompt for the grid.
  </Step>
  <Step title="Add rows">
    Add the items to rate as rows (sub-questions), for example: product names, budget categories, or time periods.
  </Step>
  <Step title="Add columns">
    Add the numeric dimensions as columns (answers), for example: estimated units or allocated budget.
  </Step>
</Steps>

## Settings

| Setting | Description |
| --- | --- |
| **Shuffle rows** | Randomly order the rows for each respondent. |
| **Shuffle answers** | Randomly order the column headers for each respondent. |
| **Show total per row** | Display a running sum at the end of each row. Enabled by default. |
| **Show total per column** | Display a running sum at the bottom of each column. |
| **Mandatory answers** | Require a numeric value in every cell before the respondent can proceed. |
| **Always show as mobile version** | Force the compact mobile layout regardless of the device used. |
| **Conditional rule on answers** | Apply conditional logic based on the values entered in individual cells. |

<Note>
  The default instruction shown to respondents is: "Type a number in each box."
</Note>

<Tip>
  If your survey requires respondents to distribute a fixed total across items, consider using a [Constant sum](/questionnaire/constant-sum) question instead. It enforces a predefined total automatically.
</Tip>
