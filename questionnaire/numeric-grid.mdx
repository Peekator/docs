A Numeric Grid question presents a matrix where respondents enter a number for each row. This is useful for collecting quantities, percentages, or scores across several items in a compact format, such as units purchased or hours spent.

## When to use this question type

- You need numeric input for multiple related items in one question.
- You want to collect quantities, percentages, or scores that can be summed or averaged.
- You prefer a compact layout instead of separate numeric entry questions.

## How to add it

<Steps>
  <Step>
    In the questionnaire builder, click **Add questions**.
  </Step>
  <Step>
    Select **Numeric Grid** from the popup.
  </Step>
  <Step>
    The question appears on the canvas. Click it to open the configuration panel and add rows, set validation rules, and define the input format.
  </Step>
</Steps>

## Settings

| Setting | Description |
| --- | --- |
| Question text | The label respondents see above the grid. |
| Rows | The items respondents provide numbers for. |
| Column label | The header for the numeric input column. |
| Minimum value | The lowest number a respondent can enter. |
| Maximum value | The highest number a respondent can enter. |
| Decimal places | Whether to allow decimals and how many. |
| Mandatory | Requires a value for every row before the respondent can continue. |
| Randomise rows | Shuffles the order of rows for each respondent. |
| Sum to total | Requires all row values to add up to a specified total. |

<Note>
  **Needs product verification:** Confirm whether "Prefix/suffix" (for example, currency symbols or "%") and "Allow negative numbers" settings exist for this question type.
</Note>

## What respondents see

Respondents see a table with rows on the left and a single numeric input column. They type a number into each cell. Input may be restricted by minimum, maximum, or decimal rules. If the question is mandatory, they must fill every row before continuing.

<Warning>
  Numeric Grid questions involve multiple validation rules. Always preview and test the full questionnaire before launching to ensure limits, totals, and mandatory rules behave correctly.
</Warning>

## Logic and piping

You can use values from individual rows in logic to show or hide later questions. For example, if a respondent enters zero for a product, you can skip follow-up questions about that product. For full instructions, see [Logic and branching](/questionnaire/logic-and-branching).

## Results in reporting

Results appear as a table with average, minimum, maximum, and total values for each row. If "Sum to total" is enabled, the total is also shown. Data can be exported for further statistical analysis.

## Example use case

A beverage company asks, "How many units of each drink did you purchase last month?" with rows for Cola, Lemonade, and Energy Drink. Respondents enter whole numbers. The company uses the totals to estimate market share.
