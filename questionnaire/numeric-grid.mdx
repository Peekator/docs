## When to use a Numeric Grid question

- You need numeric answers for several related items.
- You want to compare amounts across categories.
- You want to calculate totals by row or column.

## Add a Numeric Grid question

1. In the Questionnaire builder, select **Add question**.
2. Select **Numeric grid**.
3. Enter your question text.
4. An **Instruction note** is added automatically. Edit it if needed.
5. Add your **Rows**. These are the items respondents will enter numbers for.
6. Add your **Columns**. These are the categories respondents will enter numbers against.

<Tip>
  You can **paste multiple rows** or **columns** into the first field. Peekator automatically separates them into individual items.
</Tip>

## Add conditions and piping

Use **Add conditional rule** in the **Ask only if** section to control whether respondents see the whole Numeric Grid.

Use **Conditional rule on answer** to add conditions to individual Grid items.

Select **Pipe answers** to use answers from earlier questions in your Numeric Grid.

For full instructions, see [Logic and branching](#) and [Piping answers](#).

## What respondents see

Respondents see a table with rows on the left and numeric input fields for each column.

If **Answers are mandatory** is enabled, respondents must enter a number in every cell. If **Always show as mobile version** is enabled, each row appears as a separate statement rather than part of a table.

## Results in reporting

Reporting displays the numeric results for each row and column. You can switch between **Average** and **Median** views.

If you enable row or column totals, the totals also appear in reporting.

## Example

Ask: “During the past 12 months, how many employees left your organisation for each of the following reasons?”

Rows:

- Dismissal
- Resignation
- Retirement

Columns:

- Male
- Female
- Other
