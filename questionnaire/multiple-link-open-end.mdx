A Multiple Link Open End question presents respondents with several linked text fields in a single question. Use this type when you want to collect multiple related free-text answers together, such as strengths and weaknesses, or first, second, and third associations with a brand.

## When to use this question type

- You need several related open-ended responses in one compact question.
- You want to keep the questionnaire short while collecting multiple verbatim answers.
- You plan to compare or code related themes across the linked fields.

## How to add it

<Steps>
  <Step>
    In the questionnaire builder, click **Add questions**.
  </Step>
  <Step>
    Select **Multiple Link Open End** from the popup.
  </Step>
  <Step>
    The question appears on the canvas. Click it to open the configuration panel and add or edit the linked text fields.
  </Step>
</Steps>

## Settings

| Setting | Description |
| --- | --- |
| Question text | The main label respondents see. |
| Text fields | The individual input fields, each with its own label or prompt. |
| Mandatory | Requires input in every field before the respondent can continue. |
| Minimum characters per field | Sets the shortest acceptable response for each field. |
| Maximum characters per field | Sets the longest acceptable response for each field. |
| Randomise fields | Shuffles the order of fields for each respondent. |

<Note>
  **Needs product verification:** Confirm whether "Validate as email/URL per field" and "Allow empty fields" settings exist for this question type.
</Note>

## What respondents see

Respondents see a single question with multiple text input fields stacked vertically, each with its own label. They type an answer into each field. If mandatory, all fields must be completed before they can continue. Character counters may show if limits are set.

## Logic and piping

You can use the presence or content of responses from individual fields in logic to show or hide later questions. For full instructions, see [Logic and branching](/questionnaire/logic-and-branching).

## Results in reporting

Responses appear as a table with one column per text field. Each column can be filtered, searched, and exported for qualitative analysis. If AI auto-coding is enabled, each field can be coded separately or together to identify themes.

## Example use case

An automotive brand asks, "What are the top three reasons you chose our brand?" with three linked fields labelled "Reason 1", "Reason 2", and "Reason 3". The responses are auto-coded to identify the most common purchase drivers.
