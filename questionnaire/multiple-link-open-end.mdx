## When to use Multiple line Open-end

- You need more than one free-text response.
- You want respondents to answer several related prompts in one question.
- You want each response to have its own label.

## Add a Multiple line Open-end question

1. In the Questionnaire builder, select **Add question**.
2. Select **Multiple line open-end**.
3. Enter your question text.
4. An **Instruction note** is added automatically. Edit it if needed.
5. Replace the default **Answer title** text with a label for each response field.
6. Select **Add answer** to add another response field.
7. Drag answer titles to change their order.

## Configure answer titles

Each **Answer title** creates a separate text field for the respondent.

For example, if you ask respondents to name three things, use answer titles such as:

- Thing No. 1
- Thing No. 2
- Thing No. 3

Use the answer settings to make an individual response required or optional.

## Add conditions

Use **Add conditional rule** in the **Ask only if** section to control whether respondents see the whole question.

For full instructions, see [Logic and branching](https://chatgpt.com/c/6a9944be-99a0-83ed-acda-754df5c50a8c#).

## What respondents see

Respondents see a separate text field for each answer title and can enter a different response in each field.

## Results and AI auto-coding

Multiple line Open-end responses can be analysed and auto-coded in the same way as standard Open-end responses.

You can create AI-generated category sets, review individual responses and edit categories or coded answers.

For full instructions, see [Open-end questions](https://chatgpt.com/c/6a9944be-99a0-83ed-acda-754df5c50a8c#).

## Example

Ask: “If you were stranded on a desert island and could only take three things with you, what would they be?”

Answer titles:

- Thing No. 1
- Thing No. 2
- Thing No. 3
