Multiple line open-end questions group several open-ended text fields under a single question. Each field is a separate sub-question, making it easy to collect multiple related free-text answers in one place without creating separate questions.

Use this type when you want respondents to list several reasons, examples, or details, for example: "List three reasons for your choice."

## Add a multiple link open-end question

<Steps>
  <Step title="Click Add Question">
    In the questionnaire builder, click **Add Question** and select **Multiple Line Open-End**.
  </Step>
  <Step title="Enter question text">
    Write a prompt that explains what respondents should provide across the fields.
  </Step>
  <Step title="Add sub-questions">
    Add each text field as a sub-question with its own label, for example: "Reason 1", "Reason 2", "Reason 3".
  </Step>
</Steps>

## Settings

There are no additional settings beyond the sub-questions themselves. Each sub-question is an individual open-text field. Add, edit, remove, or reorder sub-questions in the question editor.

<Note>
  The default instruction shown to respondents is: "Enter one suggestion per line."
</Note>
