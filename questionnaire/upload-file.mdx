Upload file questions let respondents attach one or more files as part of their survey response. Use this type when you need to collect supporting documents, photos, screenshots, design files, or any material that cannot be captured through standard question types.

## Add an upload file question

<Steps>
  <Step title="Click Add Question">
    In the questionnaire builder, click **Add Question** and select **Upload File**.
  </Step>
  <Step title="Enter question text">
    Write a prompt explaining what respondents should upload, for example: `Please upload a photo of your receipt.`
  </Step>
</Steps>

## Settings

Upload file questions have no additional configuration settings beyond the question text and instruction.

<Note>
  The default instruction shown to respondents is: "You can upload up to 5 files."
</Note>

## Common use cases

- Receipts, invoices, or proof of purchase
- Photo submissions (product photos, before/after images)
- Creative submissions (designs, videos, portfolios)
- Screenshots or error logs in feedback studies
