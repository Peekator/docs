An Upload File question lets respondents attach files directly to their survey response. Use this type when you need receipts, screenshots, photos, audio recordings, or any other file type that supports your research objectives. This is common in customer support research, product testing, and ethnographic studies.

## When to use this question type

- You need visual evidence, such as photos of a product in use or screenshots of an issue.
- You want respondents to submit documents, for example, invoices or consent forms.
- You are running a creative or design contest where submissions are required.

## How to add it

<Steps>
  <Step>
    In the questionnaire builder, click **Add questions**.
  </Step>
  <Step>
    Select **Upload File** from the popup.
  </Step>
  <Step>
    The question appears on the canvas. Click it to open the configuration panel and set file type limits, size limits, and the number of files allowed.
  </Step>
</Steps>

## Settings

| Setting | Description |
| --- | --- |
| Question text | The label respondents see, for example, "Please upload a photo of your receipt." |
| Allowed file types | The formats respondents can upload, for example, JPG, PNG, PDF, MP4. |
| Maximum file size | The largest file size permitted per upload, in megabytes. |
| Maximum number of files | The highest number of files a respondent can attach. |
| Mandatory | Requires at least one file upload before the respondent can continue. |

<Note>
  **Needs product verification:** Confirm whether "Drag-and-drop area" and "Camera capture on mobile" settings exist for this question type.
</Note>

## What respondents see

Respondents see an upload area with a button to browse their device or drag and drop files. They select one or more files within the allowed types and size limits. A progress indicator shows upload status. If mandatory, the "Next" button remains disabled until at least one valid file is uploaded.

## Logic and piping

You can use the presence or absence of an upload in logic to show or hide later questions. For example, if a respondent uploads a file, you can skip a text description question. For full instructions, see [Logic and branching](/questionnaire/logic-and-branching).

## Results in reporting

Uploaded files are listed in the response view with download links. You can view, download, and organise files per respondent. File metadata, such as upload time and file size, may also be shown. Files are included in exports where supported.

## Example use case

A consumer electronics company runs a product test and asks participants to upload a photo of the product installed in their home. The images are reviewed to verify installation context and used in a follow-up qualitative analysis.
