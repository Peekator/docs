## When to use an Upload file question

Use this question when respondents need to provide files, for example:

- photos of a product or receipt;
- a short video;
- creative work or design files; or
- documents that support their response.

## Add an Upload file question

1. In the questionnaire builder, select **Add questions**.
2. Choose **Upload file**.
3. Enter the question text.
4. Save the question.

<Info>
  An **Instruction note** is added automatically. You can edit it to give respondents additional guidance, including the number or type of files you need.
</Info>

<Note>
  Respondents can upload up to five files.
</Note>

## Conditional logic

Under **Ask only if**, select **Add conditional rule** to control whether the entire Upload file question is shown, based on an earlier answer.

For more information, see [Logic and branching](/questionnaire/logic-and-branching).

## What respondents see

Respondents see an upload area where they can attach one or more files to answer the question.

Make the question clear about what they should upload. For example: _“Please upload up to five photos of your current workspace.”_

## Results in reporting

Results list the files submitted by respondents, including each file’s name and type.

You can:

- select **View all** to review all uploaded files;
- select **Download all** to download every file; or
- view or download individual files from the list.

## Example use case

A retailer asks customers to upload photos of how they use a product at home.

The uploaded images give the team visual evidence of real-life use cases, helping them identify common behaviours and opportunities for improvement.
