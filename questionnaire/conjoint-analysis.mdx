Conjoint analysis presents respondents with product profiles made up of different attribute combinations and asks them to choose their preferred option. By analyzing choices across multiple sets, you can uncover which attributes and specific levels most influence purchase decisions.

Use conjoint when you need to optimize product design, pricing structures, or feature bundles.

## Add a conjoint analysis question

<Steps>
  <Step title="Click Add Question">
    In the questionnaire builder, click **Add Question** and select **Conjoint Analysis**.
  </Step>
  <Step title="Add attribute categories">
    Add the product dimensions to test (for example: Price, Brand, Features). Each category becomes a column in the profile card.
  </Step>
  <Step title="Add attribute levels">
    For each category, add the specific values respondents will see (for example: €10, €15, €20).
  </Step>
  <Step title="Configure set and profile count">
    Set how many profiles appear per comparison set and how many sets each respondent completes.
  </Step>
</Steps>

## Settings

| Setting | Description |
| --- | --- |
| **Attribute categories** | The product dimensions and their levels. Add one category per attribute (for example, Price) and add the levels within it (for example, €10, €15, €20). |
| **Enable ratings** | Also ask respondents to rate each profile in addition to selecting their preferred one. |
| **Profiles per set** | Number of product profiles shown side by side in each comparison task. Default is `3`. |
| **Sets per respondent** | Number of comparison tasks each respondent completes. Default is `4`. |

<Note>
  Peekator generates the profile combinations automatically to ensure balanced experimental design across respondents.
</Note>
