## When to use Conjoint analysis

Use Conjoint analysis when you want to understand trade-offs between several parts of an offer, such as:

- product features and price;
- service packages;
- brand or policy propositions; or
- different versions of a concept.

It helps you assess the relative value of complete profiles, rather than asking respondents to rate each feature separately.

## Add a Conjoint analysis question

1. In the questionnaire builder, select **Add questions**.
2. Choose **Conjoint analysis**.
3. Enter the question text.
4. Add an attribute, then add its possible levels.
5. Repeat this for every attribute you want to test.

## Configure attributes and levels

An **attribute** is one part of the offer you want to test, such as price, delivery time or subscription length.

A **level** is a possible version of that attribute, such as _£15 per month_, _next-day delivery_ or _12-month contract_.

Select **Add attribute** to add another attribute. Under each attribute, select **Add level** to add the possible levels.

Use realistic, clearly different levels. Each profile shown to respondents contains one level from every attribute.

## Configure the study

In **Settings**, configure how many profiles respondents see:

| Setting | Description |
| :-- | :-- |
| **Profiles per set** | Sets the number of profiles shown together in each comparison set. |
| **Sets per respondent** | Sets how many comparison sets each respondent sees. |
| **Ask respondents to rate each profile** | Collects a rating for every profile shown |

## Conditional logic

Under **Ask only if**, select **Add conditional rule** to control whether the entire Conjoint analysis question is shown, based on an earlier answer.

For more information, see [Logic and branching](/questionnaire/logic-and-branching).

## What respondents see

Respondents see several sets of profiles. Each profile is a different combination of your attribute levels.

For example, a profile might combine:

- 30 GB of data;
- a 12-month contract; and
- a £25 monthly price.

This lets respondents compare complete offers and make realistic trade-offs.

## Results in reporting

Results rank the tested profile combinations and show their **Value to customer**.

A higher Value to customer score indicates that the profile is relatively more attractive to respondents than profiles with lower scores. Use the ranking to identify the strongest combinations of attributes and levels.

The score is comparative: use it to understand which profiles perform better or worse within the same Conjoint analysis, rather than as a standalone percentage.

## Example use case

A streaming service wants to decide which subscription package to launch. It tests combinations of monthly price, advertising, video quality and the number of simultaneous users.

The Conjoint results show which package combinations provide the greatest value to customers, helping the team make informed product and pricing decisions.
