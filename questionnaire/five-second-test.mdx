## When to use this question type

Use a 5 Second Test when you want to understand:

- What respondents notice first in an advert, design or package.
- Whether the main message is clear.
- Which elements are memorable after a brief exposure.
- The immediate impression created by a visual.

## Add a 5 Second Test question

1. In the questionnaire builder, select **Add questions**.
2. Select **5 Second Test**.
3. Enter the **Introduction** respondents see before the image.
4. Edit the **Introduction instruction note** if needed.
5. Upload the image to test.
6. Enter the question respondents answer after seeing the image.
7. Edit the **Instruction note** if needed.
8. Select **Save question**.

<Info>
  You can use one image per test. Uploading a new image removes the previous one.
</Info>

## Conditions

Use **Add conditional rule** under **Ask only if** to control whether the 5 Second Test is shown, based on an earlier answer.

For more information, see [Logic and branching](https://chatgpt.com/c/6a9944be-99a0-83ed-acda-754df5c50a8c#).

## What respondents see

Respondents first see the introduction and select **Next** when they are ready. The image is then shown for the exposure time you set.

Once the image disappears, respondents answer your question in their own words.

## Results in reporting

Results show a preview of the tested image alongside respondents’ answers. You can review the raw responses or use **AI auto-code answers** to group similar responses into categories and identify common themes.

For more information, see [Auto-code open ended responses](https://chatgpt.com/c/6a9944be-99a0-83ed-acda-754df5c50a8c#).

## Example use case

A brand shows a new advert for five seconds and asks, “What was the main message of the advert?” The responses show whether respondents understood the intended message and which visual elements they remembered.
