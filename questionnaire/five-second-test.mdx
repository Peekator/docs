A 5 Second Test question shows respondents an image for exactly five seconds, then asks them what they remember or what impression they formed. This is a standard UX research method for testing visual hierarchy, brand recall, and the clarity of designs, advertisements, or packaging.

## When to use this question type

- You want to measure first impressions and immediate recall of a visual design.
- You need to test whether key messages or branding elements are noticed quickly.
- You want to compare multiple designs by the speed at which they communicate their purpose.

## How to add it

<Steps>
  <Step>
    In the questionnaire builder, click **Add questions**.
  </Step>
  <Step>
    Select **5 Second Test** from the popup.
  </Step>
  <Step>
    The question appears on the canvas. Click it to open the configuration panel and upload the image and set the follow-up question.
  </Step>
</Steps>

## Settings

| Setting | Description |
| --- | --- |
| Image | The image, screenshot, or design to display for five seconds. |
| Display duration | Fixed at five seconds for this question type. |
| Follow-up question | The question asked after the image disappears, for example, "What do you remember?" or "What is this page for?" |
| Answer format | The type of follow-up input: open text, single choice, or multiple choice. |

<Note>
  **Needs product verification:** Confirm whether "Blur image after display" and "Allow zoom" settings exist for this question type.
</Note>

## What respondents see

Respondents see an image displayed full screen or in a framed area for exactly five seconds. A timer counts down. After the image disappears, the follow-up question appears. Respondents answer based only on what they remember from the brief exposure.

<Warning>
  5 Second Test questions involve timed media and follow-up logic. Always preview and test the full questionnaire before launching to ensure the image loads correctly and the timer behaves as expected.
</Warning>

## Logic and piping

You can use the follow-up answer in logic to show or hide later questions. For example, if a respondent correctly identifies the brand, you can skip a brand awareness question later. For full instructions, see [Logic and branching](/questionnaire/logic-and-branching).

## Results in reporting

Results show the image, the follow-up question, and a summary of responses. If the follow-up was open-ended, verbatim answers are listed and can be auto-coded. If it was a choice question, counts and percentages are shown. Time-to-answer metrics may also be available.

## Example use case

A fintech startup tests a new landing page design. Respondents see the page for five seconds, then are asked, "What is the main action this page wants you to take?" The results reveal whether the "Open an account" call-to-action is prominent enough.
