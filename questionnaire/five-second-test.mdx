The 5 second test shows respondents an image for a brief, configurable exposure period (default 5 seconds) and then asks what they remember or noticed. Use it for first-impression testing of designs, advertisements, landing pages, or logos.

## Add a 5 second test

<Steps>
  <Step title="Click Add Question">
    In the questionnaire builder, click **Add Question** and select **5 Second Test**.
  </Step>
  <Step title="Upload the image">
    Upload the image or design file you want to show respondents.
  </Step>
  <Step title="Set exposure time">
    Set how many seconds the image should be visible. Default is `5`.
  </Step>
  <Step title="Enter the follow-up question">
    Add the question text respondents see after the image disappears, for example: `What do you remember from the image?`
  </Step>
</Steps>

## Settings

| Setting | Description |
| --- | --- |
| **Image** | Upload the image or design file to display during the test. |
| **Exposure time** | Number of seconds the image is shown. Default is `5`. |
| **Show timer** | Display a visible countdown timer to the respondent during exposure. Enabled by default. |
| **Introduction content** | Optional introductory text shown on a screen before the image is displayed. |
| **Introduction instruction note** | Instruction shown on the intro screen. Default: "Click 'Next' when you are ready to start." |
| **Show as single line** | Show the follow-up text input as a single-line field instead of a textarea. |
| **Show large transcribe design** | Show an expanded transcription interface for the follow-up response. |
| **Save audio files** | Record and save the respondent's audio input alongside the text response. |

<Note>
  The default follow-up instruction shown to respondents is: "Please type your answer below."
</Note>
