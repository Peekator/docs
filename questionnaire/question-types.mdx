When you click **Add question** in the Questionnaire menu, a popup opens with all available question types organised into 6 sections. Click any type to see a respondent-facing preview on the right side of the popup, then click **Confirm question type** to add it to your questionnaire.

## Standard

General-purpose question types suitable for most surveys.

| Question type | Description |
| --- | --- |
| **Single choice** | Respondents select exactly one answer from a list. |
| **Multiple choice** | Respondents select one or more answers from a list. |
| **Grid** | Rate multiple items across the same set of columns (also known as a matrix). |
| **Numeric grid** | A grid where responses are numeric values entered per cell. |
| **Numeric entry** | Respondents type a number as their answer. |
| **Ranking** | Respondents drag items into their preferred order. |
| **Net Promoter Score (NPS)** | Standard 0–10 likelihood-to-recommend scale with automatic score calculation. |
| **Open-end** | Free-text field for qualitative responses. |
| **Multiple link open-end** | Multiple open-ended fields linked together in a single question. |
| **Date** | Respondents select a date from a date picker. |
| **Information screen** | A non-question screen that displays text or instructions to the respondent. |

## Translations

## AI

| Question type | Description |
| --- | --- |
| **Conversational AI** | An AI-driven question that adapts follow-up prompts dynamically based on respondent answers. |

## UX Research

Specialised question types for user experience studies.

| Question type | Description |
| --- | --- |
| **5 second test** | Show respondents an image or design for 5 seconds and collect their immediate impressions. |
| **Click test** | Respondents click on a specific area of an image or interface to indicate their preference or answer. |
| **Card sort** | Respondents organise cards into groups, used to inform information architecture and navigation design. |
| **Website test** | Capture respondent behaviour and feedback while they interact with a live or prototype website. |

## Market Research

Advanced question types for quantitative market research methodologies.

| Question type | Description |
| --- | --- |
| **MaxDiff** | Respondents indicate the most and least preferred items from a set, measuring relative preference strength. |
| **Conjoint analysis** | Respondents evaluate product or feature combinations to reveal what attributes drive choice. |
| **Constant sum** | Respondents distribute a fixed number of points (e.g. 100) across options to indicate relative importance. |
| **Quadrant matrix** | A two-axis grid where respondents position items across four quadrants (e.g. importance vs. satisfaction). |
| **Pairwise comparison** | Respondents compare two options at a time and choose their preferred one, across multiple pairs. |
| **Upload file** | Respondents upload a file as their answer (image, PDF, or document). |
| **Gabor Granger** | A price sensitivity method that identifies the optimal price point by testing willingness to pay at different price levels. |
| **Van Westendorp** | A pricing research method that asks four price threshold questions to determine acceptable price ranges. |

## Interview

| Question type | Description |
| --- | --- |
| **Interview topic** | A structured topic block used in interview-format research to guide moderator-led conversations. |

## How to add a question

<Steps>
  <Step title="Click Add question">
    In the Questionnaire menu on the left, click **Add question**. The question type popup opens.
  </Step>
  <Step title="Browse and select a type">
    Browse the six sections and click the question type you want. A respondent-facing preview appears on the right side of the popup.
  </Step>
  <Step title="Click Confirm question type">
    Click **Confirm question type** to add the question to your questionnaire. The question appears in the canvas and is ready to configure.
  </Step>
</Steps>
