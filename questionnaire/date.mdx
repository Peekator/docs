Date questions present respondents with a calendar picker so they can select a specific date. Use this type to collect birthdays, appointment dates, purchase dates, or any other calendar-based information.

## Add a date question

<Steps>
  <Step title="Click Add Question">
    In the questionnaire builder, click **Add Question** and select **Date**.
  </Step>
  <Step title="Enter question text">
    Write a prompt, for example: `When did you make your most recent purchase?`
  </Step>
  <Step title="Configure settings">
    Set date range restrictions or enable multiple date selection as needed.
  </Step>
</Steps>

## Settings

| Setting | Description |
| --- | --- |
| **Start date** | Restrict the calendar so respondents can only select dates on or after this date. |
| **End date** | Restrict the calendar so respondents can only select dates on or before this date. |
| **Multiple choices** | Allow respondents to select more than one date. |
| **Auto-skip with current date** | Automatically fill the answer with today's date and skip the question without showing it to the respondent. |

<Note>
  The default instruction shown to respondents is: "Select the date from the calendar."
</Note>

<Tip>
  Use **Auto-skip with current date** to silently record the survey completion date without showing a calendar to respondents.
</Tip>
