A Date question asks respondents to provide a date using a date picker or typed input. Use this type for collecting birth dates, purchase dates, event attendance dates, or any other specific point in time you need for segmentation or validation.

## When to use this question type

- You need an exact date rather than a month, year, or age range.
- You want to validate that a date falls within a specific range, for example, in the past or future.
- You plan to segment results by date, such as recent purchasers versus lapsed customers.

## How to add it

<Steps>
  <Step>
    In the questionnaire builder, click **Add questions**.
  </Step>
  <Step>
    Select **Date** from the popup.
  </Step>
  <Step>
    The question appears on the canvas. Click it to open the configuration panel and set the label, format, and range limits.
  </Step>
</Steps>

## Settings

| Setting | Description |
| --- | --- |
| Question text | The label respondents see. |
| Date format | The display format, for example, DD/MM/YYYY or MM/DD/YYYY. |
| Minimum date | The earliest date a respondent can select. |
| Maximum date | The latest date a respondent can select. |
| Mandatory | Requires a date selection before the respondent can continue. |
| Default date | A pre-filled date, if any. |

<Note>
  **Needs product verification:** Confirm whether "Date and time" (including time picker) and "Calendar start day" (Monday vs Sunday) settings exist for this question type.
</Note>

## What respondents see

Respondents see a date input field, often with a calendar icon that opens a date picker. They can click a date in the calendar or type directly into the field if permitted. Dates outside the set range are rejected. If the question is mandatory, the "Next" button remains disabled until a valid date is entered.

## Logic and piping

You can use the date value in logic to show or hide later questions. For example, if a respondent selects a date more than 12 months ago, you can branch to a re-engagement question. For full instructions, see [Logic and branching](/questionnaire/logic-and-branching).

## Results in reporting

Results appear as a distribution of responses by day, month, or year, depending on the range of data collected. You can also view minimum, maximum, and average dates. Raw values are available in exports for time-based segmentation.

## Example use case

A travel company asks, "When did you last book a holiday with us?" with a maximum date of today. Respondents who booked within the last six months are routed to a satisfaction question, while those who booked longer ago are asked what would bring them back.
