## When to use this question type

Use a Date question when you need to:

- Collect one or more dates in a consistent format.
- Limit selections to a specific date range.
- Record the current date automatically.

## Add a Date question

1. In the questionnaire builder, select **Add questions**.
2. Select **Date**.
3. Enter your question text.
4. Edit the **Instruction note** if respondents need additional guidance.
5. Select **Save question**.

## Configure the question

Select **See more** in the settings panel to configure the available options.

| Setting | Description |
| :-- | :-- |
| **Multiple choices** | Allows respondents to select more than one date. |
| **Skip question and auto fill with current time** | Skips the question and records the current date automatically. |
| **Start date** | Sets the earliest date respondents can select. |
| **End date** | Sets the latest date respondents can select. |
| **Skip if no query string** | Shows the question only when the specified query string is present. |
| **Query string name** | Enter the query string that controls whether the question is shown. |

## Conditions

Use **Add conditional rule** under **Ask only if** to control whether the whole Date question is shown, based on an earlier answer.

For more information, see [Logic and branching](https://chatgpt.com/c/6a9944be-99a0-83ed-acda-754df5c50a8c#).

## What respondents see

Respondents select a date using a calendar. If **Multiple choices** is enabled, they can select more than one date. If you set a start or end date, dates outside that range are unavailable.

## Results in reporting

Results appear in a calendar view, showing the percentage of respondents who selected each date. Choose a time period, such as one month, three months or one year, or set a custom date range to explore the results.

## Example use case

A training provider asks, “Which date would you prefer for your course?” They limit the available dates to the upcoming course period, so respondents can choose only from valid dates.
