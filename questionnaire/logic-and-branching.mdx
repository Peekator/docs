  Show this question or group **if** an earlier answer matches the rule you set.

## Conditions on questions

Every question has an **Ask only if** area. Use it when a question should appear only for certain respondents.

If the condition is not met, Peekator skips the question.

### Add a condition

1. Select the question in the questionnaire builder.
2. Under **Ask only if**, select **Add conditional rule**.
3. Choose the earlier question to use as the condition.
4. Select a rule: **IS** or **IS NOT**.
5. Select the relevant answer or answers.
6. Select **Confirm**.

Use an earlier question as the condition source, so Peekator can evaluate the respondent’s answer before deciding whether to show the question.

### Choose more than one answer

If you select **IS** and then choose more than one answer from the same source question, Peekator automatically changes the label to **IS EITHER**.

For example, you may ask:

> Which channels does your organisation currently use?

To show a follow-up question to respondents who use email or SMS:

1. Select **Which channels does your organisation currently use?**
2. Select **IS**.
3. Select _Email_ and _SMS_.

Peekator then displays:

> **Which channels does your organisation currently use?** **IS EITHER** _Email_ **OR** _SMS_

This is still one condition. The respondent only needs to have selected one of the chosen answers.

<Note>
  **IS EITHER** is not a separate rule you select. It appears automatically when an **IS** condition includes more than one answer.
</Note>

## Combine multiple conditions

The first dropdown in the **Ask only if** window controls how multiple condition rows work together. This is separate from **IS** and **IS NOT**, which apply to each individual condition.

      <td>Every condition is met.</td>

    <tr>

    </tr>
    <tr>
      <td>**At most**</td>
      <td>No more than the selected number of conditions are met.</td>
    </tr>
    <tr>

      <td>The selected number of conditions are met.</td>
    </tr>

For example:

- Use **Any** to show a question when a respondent uses _Email_ or _SMS_.
- Use **All** to show a question only when a respondent uses _Email_ and works for an organisation with 250 or more employees.
- Use **Exactly 2 conditions** to show a question only when exactly two listed conditions are met.

Select **Add another condition** to add more condition rows.

## Conditions on answers

Use an answer condition to show or hide a specific answer option within a question. Unlike a question condition, it does not hide the whole question.

Use answer conditions when the available answers should depend on an earlier response. For example, only show relevant office locations once a respondent has selected their country.

Answer conditions are available for question types with answer options.

### Add a condition to an answer

1. Select the question.
2. In **Settings**, select **Conditional rule on answer**.
3. Select the conditional-rule arrow to the left of the answer you want to control.
4. In the **Condition answer** window, select **Include** or **Exclude**.
5. Choose the earlier question, then set the answer condition.
6. Select **Confirm** and save the question.

For example, you could ask:

> Where is your organisation based?

Then, in a later **Select your office location** question:

- Include _London_ and _Manchester_ if the organisation is based in the _United Kingdom_.
- Include _New York_ and _Chicago_ if the organisation is based in the _United States_.

The respondent sees only the office locations relevant to their earlier answer.

You can add more than one condition to an answer and combine them using the same **Any**, **All**, **At least**, **At most** and **Exactly** options used for question conditions.

## Conditions on groups

You can apply the same conditions to a **Group**.

When editing a group, use **Ask only if** and select **Add conditional rule**. Configure the condition in the same way as for an individual question.

If the group condition is not met, Peekator skips the entire group and every question inside it.

Use a group condition when several related follow-up questions should be shown to the same respondents. For example, show a group of account-management questions only to enterprise customers.

## Use hidden variables for reusable segments

Use direct question or group conditions for straightforward logic.

If you need a more specific segment, cannot express the logic cleanly with direct conditions, or want to reuse the same segment across several questions or groups, create a **Hidden Variable**.

A hidden variable turns one or more earlier answers into a named segment, such as _Enterprise customers_. You can then use that segment as the source for a question or group condition.

For instructions, see [Hidden variables](https://chatgpt.com/c/6a9944be-99a0-83ed-acda-754df5c50a8c#).

## Test your logic

Before launch, use **Preview** to test each path through the questionnaire and check that questions and groups appear as intended.
