A group can have its own conditions, and you can shuffle the questions inside it. Use **group rotations** to change the order in which whole groups appear, or to show each respondent only a randomly selected subset of groups.

<Tip>
  Groups are particularly useful for concept testing.
</Tip>

## Add a group

1. In the questionnaire builder, select **Options**.
2. Select **Add Group**.
3. A new group container appears in the **Questionnaire menu**.
4. Select the group to open its settings.
5. Enter a **Group title**.
6. Drag and drop questions from the Questionnaire menu into the group container.
7. Select **Save group**.

You can add any relevant questions to the group, such as a concept image, a concept description and the questions used to evaluate it.

## Add conditions to a group

Use **Ask only if** to control whether the whole group appears for a respondent.

1. Open the group.
2. Under **Ask only if**, select **Add conditional rule**.
3. Set the conditions in the same way as for a question.
4. Save the group.

When the conditions are met, the respondent sees every question in the group. When they are not met, the whole group is skipped.

For more information, see [Logic and branching](/questionnaire/logic-and-branching).

## Shuffle questions inside a group

Enable **Shuffle questions inside the group** in the group’s **Settings**.

This randomises the order of the questions within that group for each respondent.

Use this when the group contains several similar questions and you want to reduce order bias.

<Note>
  Shuffling questions inside a group is different from group rotation. It changes the order of individual questions, not the order of whole groups.
</Note>

## Set group rotations

Use group rotations to shuffle whole groups between respondents.

This is useful for concept testing. For example, create one group for each concept:

- **Concept A**: concept material and evaluation questions
- **Concept B**: concept material and evaluation questions
- **Concept C**: concept material and evaluation questions

Then use group rotations to control which concepts each respondent sees and in which order.

### Create a rotation

1. Select **Set more**.
2. Select **Set Group Rotations**.
3. Select the groups you want to rotate.
4. Under **Show in survey**, choose how many of those groups respondents should see.
5. Select **Save**.

Use **Add new rotation** to create a separate rotation for another set of groups.

## Test the questionnaire

Preview the questionnaire several times after setting up groups and rotations.

Check that:

- questions are inside the correct group;
- group conditions work as expected;
- questions shuffle only when intended; and
- respondents see the correct group order or number of concept groups.
