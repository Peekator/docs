Click test questions record the exact coordinates of where respondents click on an uploaded image. Use this type to test usability, visual hierarchy, or information architecture by asking questions like "Where would you click to find settings?" or "Which part of this image stands out most?"

Results are shown as a heatmap overlay on your image in the dashboard.

## Add a click test question

<Steps>
  <Step title="Click Add Question">
    In the questionnaire builder, click **Add Question** and select **Click Test**.
  </Step>
  <Step title="Upload the image">
    Upload the image or interface screenshot respondents will click on.
  </Step>
  <Step title="Enter the question prompt">
    Write clear instructions, for example: `Click where you would expect to find customer support.`
  </Step>
  <Step title="Configure click settings">
    Set the minimum and maximum number of clicks allowed and optionally define a success area.
  </Step>
</Steps>

## Settings

| Setting | Description |
| --- | --- |
| **Image** | Upload the image respondents will click on. |
| **Minimum clicks** | The fewest clicks required before the respondent can proceed. Default is `1`. |
| **Maximum clicks** | The most clicks a respondent can place on the image. Default is `1`. |
| **Radius** | The visual radius of each click dot in the heatmap results visualization. Default is `10`. |
| **Success area** | Define a rectangular area (top, bottom, left, right as percentages) that counts as a correct click. Used to measure accuracy rate in results. |

<Note>
  The default instruction shown to respondents is: "Tap on the area of the image."
</Note>
