Pairwise comparison questions show respondents two items at a time and ask them to choose their preferred one. The selected item stays on screen and faces a new challenger. This continues until a single preferred item remains. The result is a ranked preference order derived from head-to-head comparisons.

Use this type for concept or message ranking, feature preference ordering, or brand/logo comparison.

## Add a pairwise comparison question

<Steps>
  <Step title="Click Add Question">
    In the questionnaire builder, click **Add Question** and select **Pairwise Comparison**.
  </Step>
  <Step title="Enter question text">
    Write the prompt respondents see for each comparison, for example: `Which of these two concepts do you prefer?`
  </Step>
  <Step title="Add items">
    Add each concept, feature, or option as an answer. Peekator will run all pairwise comparisons automatically.
  </Step>
</Steps>

## Settings

Pairwise comparison questions have no additional configuration settings beyond the items themselves. Add, edit, remove, or reorder the answer options in the question editor.

<Note>
  The default instruction shown to respondents is: "You will see two concepts at a time. Select the one you prefer. The chosen option stays and a new one appears for comparison. Keep selecting until only one option remains."
</Note>
