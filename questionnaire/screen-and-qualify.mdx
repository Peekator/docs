## Regular screenout

Use a regular screenout when one answer should immediately screen a respondent out, or when a required answer has not been selected.

For each answer option, open its answer settings and select one of the following:

- **Screenout if this answer is selected**
- **Screenout if this answer isn't selected**

For example, ask:

> Are you personally involved in decisions about purchasing software for your organisation?

If only decision-makers should continue, add **Screenout if this answer is selected** to the answer **No**.

Use regular screenout only for straightforward, single-answer rules.

## When not to use regular screenout

Do not use regular screenout when a respondent can qualify through more than one muliple-choice answer.

For example, ask:

> Which of the following are you involved in at work? Select all that apply.

A respondent should qualify if they select either:

- **Purchasing software**; or
- **Managing IT systems**.

Regular screenout cannot create this rule correctly:

- screening out every other answer could also screen out someone who selected a qualifying answer alongside another option; and
- adding **isn't selected** to both qualifying answers would require respondents to select both answers, rather than either one.

Use **Advanced Screenout** for this type of rule.

## Advanced Screenout

Use **Advanced Screenout** when your screener requires condition logic.

It is the recommended option for:

- Grid questions;
- Multiple choice questions where respondents can qualify through one of several answers;
- conditions across more than one question; and
- any screener that cannot be created with a regular per-answer screenout.

To add one:

1. In the questionnaire builder, open **Options**.
2. Select **Filter respondents (Advanced Screenout)**.
3. Under **Ask only if**, select **Add conditional rule**.
4. Set up the conditions in the same way as question and group conditions.
5. Choose the required advanced-screenout outcome.
6. Save the filter.

<Note>
  Conditions are required for an Advanced Screenout to work.
</Note>

For the work-responsibility example above, create a condition where the question **IS EITHER** **Purchasing software** or **Managing IT systems**. Then select **Let respondents through only if they meet the conditions**.

For more information on creating conditions, see [Logic and branching](https://chatgpt.com/logic-and-branching).

## Use quality control for data-quality failures

Use the two **quality control** options for respondents who should fail a data-quality check, rather than for ordinary eligibility criteria.

A quality-control failure redirects the respondent to the panel’s quality-fail outcome instead of a normal screenout. This is important because it prevents quality failures from increasing your screenout or dropout rate.

For example, use quality control for failed attention checks, inconsistent answers or other evidence that a respondent did not complete the survey properly.

## Test your screener

Preview and test the questionnaire with qualifying and non-qualifying answers before launching.

Check that:

- qualifying respondents continue;
- non-qualifying respondents receive the intended outcome; and
- quality-control failures are sent to the quality-fail outcome rather than a standard screenout.
