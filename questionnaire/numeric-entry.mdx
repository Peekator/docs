A Numeric Entry question asks respondents to type a number into a single input field. Use this type when you need exact quantities, such as age, income, number of employees, or units purchased, rather than a pre-defined list of ranges.

## When to use this question type

- You need an exact numeric value rather than a range or category.
- You want to calculate averages, totals, or perform statistical analysis on the raw data.
- You need to validate input within a specific range or format.

## How to add it

<Steps>
  <Step>
    In the questionnaire builder, click **Add questions**.
  </Step>
  <Step>
    Select **Numeric Entry** from the popup.
  </Step>
  <Step>
    The question appears on the canvas. Click it to open the configuration panel and set the label, limits, and format.
  </Step>
</Steps>

## Settings

| Setting | Description |
| --- | --- |
| Question text | The label respondents see. |
| Minimum value | The lowest number a respondent can enter. |
| Maximum value | The highest number a respondent can enter. |
| Decimal places | Whether to allow decimals and how many. |
| Prefix | A symbol or text shown before the input, for example, a currency symbol. |
| Suffix | A symbol or text shown after the input, for example, "%" or "kg". |
| Mandatory | Requires a value before the respondent can continue. |

<Note>
  **Needs product verification:** Confirm whether "Allow negative numbers" and "Slider display" settings exist for this question type.
</Note>

## What respondents see

Respondents see a single text input field, often with a prefix or suffix. They type a number. The field may reject non-numeric characters or values outside the set range. If the question is mandatory, the "Next" button remains disabled until a valid number is entered.

## Logic and piping

You can use the numeric value in logic to show or hide later questions. For example, if a respondent enters an age below 18, you can branch to a different set of questions. For full instructions, see [Logic and branching](/questionnaire/logic-and-branching).

## Results in reporting

Results appear as descriptive statistics: average, median, minimum, maximum, and standard deviation. A histogram shows the distribution of responses. Raw values are available in exports for further analysis.

## Example use case

A B2B software company asks, "How many employees does your organisation have?" with a minimum of 1 and no maximum. The raw numbers let them segment results by company size in analysis.
