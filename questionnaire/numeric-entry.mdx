## When to use Numeric Entry

- You need one numeric response.
- You want to collect a quantity, amount, score or rating.
- You need to set an acceptable response range.

## Add a Numeric Entry question

1. In the Questionnaire builder, select **Add question**.
2. Select **Numeric entry**.
3. Enter your question text.
4. An **Instruction note** is added automatically. Edit it if needed, for example to say “Please enter a number”.
5. Choose the entry type and configure the response settings.

## Add conditions

Use **Add conditional rule** in the **Ask only if** section to control whether respondents see the question.

For full instructions, see [Logic and branching](https://chatgpt.com/c/6a9944be-99a0-83ed-acda-754df5c50a8c#).

## What respondents see

The response format depends on the entry type you select:

- **Numeric**: respondents type a number.
- **Digits**: respondents enter a whole number.
- **Slider**: respondents choose a value on a scale.
- **Stars**: respondents choose a rating using stars.
- **Dropdown**: respondents select a numeric value from a list.

## Results in reporting

Numeric Entry results show the **average result** by default.

You can create custom categories to group responses into ranges, such as age groups or spend bands.

1. In the results view, select **Add custom categories to show in the graph**.
2. Enter the start and end value for each category.
3. Select **Create categories and place responses**.

You can then view the distribution by percentage or response count.

## Example

Ask: “How old are you?”

Use the **Numeric** entry type and create reporting categories such as:

- 18 to 24
- 25 to 34
- 35 to 44
- 45 to 54
- 55 to 64
- 65 and over
