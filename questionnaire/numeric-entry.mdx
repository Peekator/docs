Numeric entry collects a single number from the respondent. Choose from five display modes to match the data you need, from a simple number field to a star rating or slider.

## Display modes

Peekator offers five modes for numeric questions:

| Mode | Description |
| --- | --- |
| **Numeric** (default) | Standard number input field. |
| **Digits** | Fixed-length digit input, for example a 4-digit PIN or code. |
| **Slider** | Range slider with configurable min, max, step, and start value. |
| **Stars** | Star rating control. **Maximum value** sets the number of stars (for example, `5` for a 5-star scale). |
| **Dropdown** | Dropdown list of numbers generated from min, max, and step values. |

## Settings

| Setting | Description |
| --- | --- |
| **Display mode** | Choose between Numeric, Digits, Slider, Stars, or Dropdown. |
| **Minimum value** | Lowest accepted number. |
| **Maximum value** | Highest accepted number. Also sets the number of stars in Stars mode. |
| **Screenout if out of range** | Screen out respondents who enter a value outside the min/max range. |
| **Currency** | Display a currency symbol next to the value. |
| **Decimal places** | Number of decimal places allowed. Default is `2`. |
| **Digits** | Number of digits required. Applies to Digits mode only. |
| **Step** | Increment per tick or step. Applies to Slider and Dropdown modes. |
| **Start value** | Initial position of the slider. Applies to Slider mode only. |

<Note>
  The default instruction shown to respondents is: "Please enter a number."
</Note>

<Tip>
  Use **Screenout if out of range** to automatically disqualify respondents who enter values outside your target range, keeping your data clean without manual review.
</Tip>
