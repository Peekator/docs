Any user in your organisation can add a new user to Peekator. Once added, user records cannot be edited or deleted, so check all details carefully before saving.

## Prerequisites

You must be logged in to Peekator to add users.

## Add a new user

<Steps>
  <Step title="Open the account menu">
    Click your name or initials in the top-right corner of any page to open the account menu.
  </Step>
  <Step title="Click Manage users">
    Select **Manage users** from the dropdown. This opens the user management page.
  </Step>
  <Step title="Click ADD USER">
    Click the **ADD USER** button to open the new user form.
  </Step>
  <Step title="Fill in the form">
    Complete the following fields:

    | Field | Required | Description |
    | --- | --- | --- |
    | First name | Yes | The new user's first name |
    | Last name | Yes | The new user's last name |
    | Email | Yes | The email address they will use to log in |
    | Client | Yes | The organisation they belong to. This is auto-populated from your account. |
    | Phone number | No | Optional contact number |
    | Setup Password | Yes | The initial password for their account |
    | Confirm Password | Yes | Re-enter the initial password to confirm |
  </Step>
  <Step title="Click Save">
    Review every detail, then click **Save** to create the account.
  </Step>
</Steps>

<Warning>
  User records cannot be edited or deleted after they have been saved. Check all details carefully before clicking Save.
</Warning>

## View existing users

The **Manage users** page displays a table of all users in your organisation with the following columns:

| Column | Description |
| --- | --- |
| First Name | The user's first name |
| Last Name | The user's last name |
| Email | The email address associated with the account |
| Client | The organisation the user belongs to |
