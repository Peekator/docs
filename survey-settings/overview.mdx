Survey settings control how respondents interact with your survey, how responses are collected, and what data appears in your exports. Open the **Setup** area of a survey, then select the **Settings** section to adjust these options.

## Respondent experience

These settings affect what respondents see before, during, and after the survey.

| Setting | Description | Default |
| --- | --- | --- |
| **IntroText** | Text shown on the welcome screen before the first question. | Empty |
| **OnCompleteText** | Message shown on the completion screen after the survey is finished. | Empty |
| **OnScreenoutText** | Message shown when a respondent is screened out. | Empty |
| **OnQuotaFullText** | Message shown when a quota group is full. | Empty |
| **EnableBackButton** | Lets respondents return to previous questions. | On |
| **ShowAverageRespondentTime** | Displays the estimated completion time on the welcome screen. | On |
| **ShouldAutoSkipWelcomeScreen** | Automatically skips the welcome screen for returning respondents. |  |
| **DisableAutoSkipOnAllQuestions** | Prevents automatic skipping across all questions. |  |

## Collection settings

These settings define when and how many responses you want to collect.

| Setting | Description | Default |
| --- | --- | --- |
| **TotalNumberOfRespondents** | Target number of completed responses. | 500 |
| **DateFrom** | Date and time when the survey opens for responses. | Empty |
| **DateTo** | Date and time when the survey closes. | Empty |
| **Language** | Language used for standard UI labels and messages. |  |
| **MarketId** | Target market or country for the survey. |  |

## Time limit for continuing

Use these settings if you want respondents to be able to pause and resume the survey later.

| Setting | Description | Default |
| --- | --- | --- |
| **AllowContinuingTheSurvey** | Lets respondents return to a partially completed survey. |  |
| **TimeLimitForContinuingInHours** | How long a partially completed session remains available. | 24 hours |

## Quality control

These settings flag responses that are completed too quickly, so you can review or exclude them.

| Setting | Description | Default |
| --- | --- | --- |
| **EnforceSpeedingQC** | Flags responses that are completed faster than the allowed minimum time. |  |
| **AverageMinutesExpected** | Expected average completion time in minutes. |  |
| **MinimumTimePercentageAllowed** | Minimum percentage of the expected time a respondent must spend. |  |

## Export settings

These settings add extra columns to your exported data.

| Setting | Description | Default |
| --- | --- | --- |
| **ShowTimeSpentOnEachQuestionInExport** | Includes a time-spent column per question in exports. |  |
| **ShowLengthOfInterviewInExport** | Includes total interview length in exports. |  |
| **ShowSpssCodeOnAllQuestionsInExport** | Includes SPSS syntax codes for all questions in exports. |  |

## Redirects

Send respondents to an external page after they finish the survey.

| Setting | Description | Default |
| --- | --- | --- |
| **ShouldRedirectAtTheEnd** | Redirects respondents to a custom URL after completion. | Off |
| **RedirectUrl** | The external URL to redirect to. | Empty |

## HTML screen title

Control the browser tab title respondents see.

| Setting | Description | Default |
| --- | --- | --- |
| **UseDefaultHtmlScreenTitle** | Uses the survey name as the browser tab title. |  |
| **DefaultHtmlScreenTitle** | Custom text for the browser tab title. | Empty |

## AI context

Link your survey to an AI summary configuration so that **Chat with Results** and **Auto-coding** use the right context.

| Setting | Description |
| --- | --- |
| **AiSummaryParametersId** | References a saved AI summary parameter set. |

## Custom CSS

Apply advanced styling to your survey with a custom stylesheet.

| Setting | Description |
| --- | --- |
| **CustomCss** | CSS rules injected into the respondent-facing survey page. |

<Warning>
  Custom CSS is an advanced feature. Incorrect styles may break the survey layout on mobile devices. Test thoroughly before launching.
</Warning>
