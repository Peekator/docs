Survey Settings is the third item under **Setup** in the survey editor, alongside Questionnaire and Distribution. It contains configuration specific to the individual survey: how respondents experience it, what the platform records, and how the data is exported.

## General

| Setting | Description |
| --- | --- |
| **Survey name** | The internal name of the survey. Used in the project view and exports. |
| **Name for respondents** | An alternative display name shown to panel respondents instead of the internal name. |
| **Language** | The primary language of the survey. Used for default text and AI analysis language. |
| **Market** | The target market for the survey, used for panel targeting and reporting. |

## Dates

| Setting | Description |
| --- | --- |
| **Start date** | The date from which the survey accepts responses. |
| **End date** | The date after which the survey stops accepting responses. |

## Response texts

These texts are shown to respondents at specific points in the survey flow. All can be customized with HTML or rich text.

| Setting | Description |
| --- | --- |
| **Intro text** | Shown on the survey welcome screen before the first question. |
| **On complete text** | Shown after a respondent successfully completes the survey. |
| **On screenout text** | Shown when a respondent is screened out by a filter question. |
| **On quota full text** | Shown when the survey's sample quota is already filled. |

## Respondent experience

| Setting | Description |
| --- | --- |
| **Enable back button** | Allow respondents to navigate back to previous questions. Enabled by default. |
| **Show average respondent time** | Display an estimated completion time to respondents. |
| **Auto-skip welcome screen** | Skip the intro screen and go directly to the first question. |
| **Disable auto-skip on all questions** | Prevent questions from auto-advancing when an answer is selected. |
| **Allow continuing the survey** | Let respondents resume an incomplete survey where they left off. Set a time limit for how long this is allowed. |
| **Custom CSS** | Apply custom CSS to the survey engine. Overrides the default and client CSS. |
| **Custom HTML screen title** | Use a custom browser tab title for the survey. |

## Speeding quality control

| Setting | Description |
| --- | --- |
| **Enforce speeding QC** | Automatically flag or reject responses completed too quickly. |
| **Average minutes expected** | Expected average completion time in minutes (used as the QC baseline). |
| **Minimum time percentage allowed** | The minimum percentage of expected time a respondent must take. Responses faster than this are rejected. |

## Redirect

| Setting | Description |
| --- | --- |
| **Redirect at the end** | Redirect respondents to an external URL after completing the survey. |
| **Redirect URL** | The URL to redirect to. |

## Campaign settings

| Setting | Description |
| --- | --- |
| **Campaign target delay** | Number of days to ignore respondents who were already targeted before re-sending campaign notifications. |

## Distribution

| Setting | Description |
| --- | --- |
| **Distribution channel type** | The active distribution channel: Link, Campaign, or Panel. Set in the Distribution section. |

## AI summary

| Setting | Description |
| --- | --- |
| **AI summary parameters** | Configure the parameters used by the AI Summary feature for this survey. See [AI Summary](/ai-analysis/ai-summary). |

## Export options

| Setting | Description |
| --- | --- |
| **Show time spent on each question** | Include a column in exports with the time (in seconds) spent on each question. |
| **Show length of interview** | Include a column in exports with the total survey duration per respondent. |
| **Show SPSS code on all questions** | Include SPSS variable codes for all questions in exports. |

## External panel providers

If your survey uses an external panel (for example via CINT integration), you can configure panel provider redirect URLs here:

- **Success URL**: redirect used when a respondent completes the survey
- **Screenout URL**: redirect used when a respondent is screened out
- **Quota full URL**: redirect used when the quota is full
