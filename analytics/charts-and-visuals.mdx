Peekator automatically generates a chart for every question in your survey based on the question type. You can switch chart types, adjust colors, toggle labels, and download any chart as a PNG or SVG for use in reports and presentations.

## Default chart types by question type

| Question type | Default chart | Alternative options |
| --- | --- | --- |
| Multiple choice | Bar chart (horizontal) | Pie chart, donut chart |
| Single choice | Bar chart (vertical) | Pie chart, donut chart |
| Rating scale | Histogram | Bar chart, average score card |
| Open-ended | Word cloud | Response list, sentiment chart |
| Matrix | Stacked bar chart | Grouped bar chart, heat map |
| Ranking | Stacked bar chart | Average rank table |
| Dropdown | Bar chart | Pie chart |
| NPS | NPS gauge | Bar chart (0-10 distribution) |
| File upload | Response count card | (no chart) |
| Date and time | Timeline chart | Calendar heat map |

## Switch the chart type

<Steps>
  <Step title="Open your survey dashboard">
    Go to the survey's analytics view and scroll to the question chart you want to change.
  </Step>
  <Step title="Click the chart menu">
    Click the **more options** icon (three dots) in the top-right corner of the chart card.
  </Step>
  <Step title="Select a chart type">
    Choose from the available alternatives in the dropdown. The chart re-renders immediately.
  </Step>
</Steps>

## Customize chart appearance

Click the chart menu and select **Edit chart** to open the chart settings panel:

- **Colors**: change the color of each data series to match your brand palette.
- **Data labels**: toggle values shown directly on bars, slices, or data points.
- **Legend**: show or hide the chart legend.
- **Title**: edit the chart title displayed above the visualization.

<Tip>
  Use your brand colors consistently across all charts before exporting for a client presentation. Set the primary color once and Peekator applies it across all charts in the survey.
</Tip>

## Download a chart

<Steps>
  <Step title="Open the chart menu">
    Click the **more options** icon in the top-right corner of the chart card.
  </Step>
  <Step title="Click Download">
    Select **Download as PNG** for a raster image suitable for documents and slides, or **Download as SVG** for a vector format that scales cleanly at any size.
  </Step>
  <Step title="Save the file">
    Your browser saves the file to your default downloads folder.
  </Step>
</Steps>
