You can start a filter in either of two ways:

- Select **Add Filter** to create a filter by question, answer or submission date.
- Select any answer directly in a chart or table to filter the Dashboard to respondents who gave that answer.

When a filter is active, every result card updates to show data for the selected respondents. The filtered respondent base is shown as **N**.

## Add a filter

1. Go to **Reporting** → **Dashboard**.
2. Select **Add Filter**.
3. Under **Filter by Questions**, select one question.
4. Select one or more answers for that question.
5. Select **Confirm selected**.

Only one question can be selected at a time in the **Add Filter** window. You can then add more filters from other questions to build a broader or more specific respondent group.

For example, select the **Gender** question and the answer **Male** to view results only from male respondents.

## Filter directly from an answer

Every answer shown in a Dashboard chart or table can be used as a filter.

1. Find the answer you want to analyse, such as **35–44** or **Male**.
2. Select the answer.
3. The Dashboard refreshes to show only respondents who selected that answer.

Use this method when exploring results and you want to investigate a group quickly without opening the filter window.

## Combine filters with And or Or

The **Question filter mode** controls how all active answer selections work together.

For example:

- In **And** mode, filtering for **Aged 25–34** and **Female** shows only female respondents aged 25–34.
- In **Or** mode, filtering for **Aged 18–24**, **Aged 25–34** and **Male** shows respondents who match any of those selections.

The active-filter area shows the selected answers and the mode currently in use.

<Tip>
  Use **And** to create a precise audience segment. Use **Or** to combine several relevant groups into one view.
</Tip>

## Filter by submission date

Use **Filter by date of submission** in the **Add Filter** window to limit results to a time period.

1. Select a **From** date.
2. Select a **To** date.
3. Add a question filter if needed.
4. Select **Confirm selected**.

You can use a date range on its own or alongside question filters. For example, view feedback collected during a particular campaign period.

## Review and remove filters

Active filters appear above the results with the question number and selected answer. The active-filter area also shows the updated respondent base, such as **N = 24**.

To remove one answer selection, select the **×** beside that answer.

To remove all selections for one question, select the **×** at the end of that question’s filter group.

Select **Clear all filters** to return to the full respondent base.

## Export filtered results

Active filters apply to Dashboard exports. Set the filters you need before exporting results, tables or reports so the export reflects the same respondent group.
