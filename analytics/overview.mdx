## Open the Dashboard

1. Open the survey you want to analyse.
2. Select **Reporting**.
3. Select **Dashboard**.

The summary may also show other fieldwork information, depending on the distribution channel and project setup.

Use the actions in the upper-right corner to:

- select **Preview Survey** to view the survey as a respondent;
- select **Export** to download results; or
- select **Share** to create a shareable Dashboard link.

## Filter the results

Use filters to analyse a particular respondent group.

You can filter results in two ways:

1. Select **Add Filter**, then choose the question and answer you want to filter by.
2. Select an answer directly in a result chart or table.

For example, you could select an age group or employment status to see how that group answered every other question.

After you apply a filter, all Dashboard results update to show the selected group only. Exports can also use the filtered results.

## Explore question results

Results are displayed in survey order, with a separate card for each question.

Each card shows:

- the question type and question text;
- the **N** value, which is the number of respondents who answered that question;
- a chart, table or other visualisation appropriate to the question type; and
- controls for changing the display or opening additional actions.

Use the controls on a question card to switch between percentages and response counts, change the view where available, or open more options.

<Note>
  If a question shows Conditions applied, not every respondent was shown that question. Its N may therefore be lower than the total survey response count.
</Note>

### Understand result visuals

Peekator automatically selects a suitable view for each question type, such as a bar chart, donut chart, matrix or table.

Use the controls on each result card to switch between percentages and response counts. Select an answer in a chart or table to filter the Dashboard by that response.

## Analyse open-ended responses

Open-ended, Conversational AI and AI Interview questions can show the original responses or AI-coded categories.

A **category set** groups similar responses into themes. Select a category set in the left-hand panel to view its results.

You can use the available controls to:

- view all responses associated with a category;
- review and edit categories;
- review and edit individual coded answers; or
- create another AI auto-code set.

Select **Add next AI auto-code** when you want to create an additional set of categories without replacing the existing one.

## Export results

Select **Export** to download survey results for further analysis or reporting.

Available export formats include:

- CSV;
- Excel;
- SPSS; 
- Dasbhoard Excel Report; and
- editable PowerPoint, with one question per slide.

## Share the Dashboard

Select **Share** to create a link to the Dashboard for colleagues or stakeholders.

You can share a view of the results without giving recipients access to the full Peekator platform. Configure the shared view and its expiry settings before sending the link.
